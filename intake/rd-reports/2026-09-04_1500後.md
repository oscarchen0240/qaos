# QA 回報 - 2026-09-04 15:00 後

分支: local

## Bug 修復

- **深層子站台被誤判成主站台**
  - 問題: 新增站台時, 上層若選的是第二層以下的子站台, 系統會把它當成主站台層 -> 站台類型與核心貨幣變成可自行選擇, 而不是跟隨上層
  - 修改: 改成直接查所選上層站台本身的資料, 類型與幣別一律取自該上層站台; 只有「沒有上層」或「上層是 admin 平台站台」才算主站台層

- **Admin 底下建不出機台類型的主站台**
  - 問題: Admin 登入後新增站台, 上層選 admin 平台站台時, 站台類型被鎖成「線上」, 核心貨幣變成唯讀繼承, 沒辦法在 admin 下面開機台主站台
  - 修改: 把 admin 平台站台當成站台樹的最上界, 掛在它下面的一律視為主站台層, 類型與核心貨幣都可自行選擇

- **切換站台類型後, 核心貨幣下拉是空白的**
  - 問題: 新增站台時把站台類型切到「機台」, 核心貨幣欄位變空白, 沒有自動選上 TWD
  - 修改: 切換類型後自動選上該類型唯一的幣別 (線上 USDT, 機台 TWD), 下拉即使沒展開過也會顯示目前的值

- **待審通知紅點不會亮**
  - 問題: 後端通知格式改版後, 待審筆數的紅點不會亮也不會響
  - 修改: 改成依站台分組取自己站台的待審筆數; 找不到自己站台就不亮紅點, 舊格式維持原本行為
