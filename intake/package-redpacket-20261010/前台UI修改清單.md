# 紅包前台 UI 修改清單（spec v02，2026-10-10）

給前台設計：從「前台調整清單」中挑出**需要改畫面**的項目，對照現行設計（Violet Arcade，線上與機台共用）。只影響邏輯、畫面不用動的項目不列在這裡，見文末。

標記說明：🔧 改現有元件　➕ 新增元件或狀態

## 不需改畫面（給前端，見完整版前台調整清單）

- 活動結束後立即移除紅包圖示
- 累計進度：全部領完後回到距下一個紅包的進度（沿用現有「1,200 / 3,000＋尚差」樣式）；累計為負時顯示 0
- 領取完成後若仍有待開啟紅包，視窗改顯示下一個紅包的金額
- 有待開啟紅包時金額顯示已抽定的結果（沿用現有金額樣式）
- 機台洗分／出金後才達標時圖示不亮起
