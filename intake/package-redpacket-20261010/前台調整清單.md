# 紅包前台調整清單（spec v02，2026-10-10）

給前台設計與前端：對照**現行設計**（Violet Arcade 大廳與紅包視窗，線上與機台共用），需要配合 `spec/紅包_spec_v02.md`「前台呈現說明」調整的項目。spec 只定義觸發時點、資料與用詞，版面與動畫仍由前台設計決定。

標記說明：✅ 現行設計已符合　🔧 需修改　➕ 需新增

| # | 區塊 | 現行設計 | 規格／調整內容 | |

| # | 區塊 | 現行設計 | 規格／調整內容 | |
