### 功能說明

洗分與出金都是**把現金交給玩家**的交易。每一筆「已完成」的機台洗分或機台出金，系統會自動在本頁產生一筆**待核實**紀錄；現金確實交到玩家手上後，操作人員在本頁把該筆紀錄轉為**已核實**。本頁是**全平台唯一的核實入口**——機台交易紀錄只顯示核實狀態，不提供操作。

兩種交易的現場流程不同，但在本頁做的事相同：

| 交易類型 | 現場流程 | 核實時點 |
| ------- | ------- | ------- |
| 機台洗分 | 店員操作洗分、當場付現，沒有任何憑據 | 付現後**立即**在本頁核實；應付金額以本頁「實際金額」欄為準 |
| 機台出金 | 機台印出收據，玩家持收據到櫃檯兌現 | 櫃檯輸入收據上的**訂單編號**查到該筆，核對後核實並付現——**核實即收據核銷** |

> ⚠️ 機台廠商提供的規格中，出金流程到「收據印出」就結束了，**沒有定義收據要如何兌現與核銷**。本頁的核銷（＝核實）為後台自訂，機台本身不參與。核銷方式採**櫃檯人工輸入訂單編號**，不引入掃碼設備（收據不需印製條碼或 QR Code）。訂單編號由平台產生，**設計為人工可朗讀、可輸入的短碼**，不依賴廠商收據的列印長度限制。

> ⚠️ **過渡期（機台暫無印表機，2026-09-03 廠商告知）**：出金完成後由前台顯示結算結果畫面（機台編碼、時間、訂單編號、結算分數）供玩家拍照，**照片代替收據**；櫃檯依照片上的訂單編號核銷，本頁流程與狀態不變。玩家未拍照時，可於機台交易紀錄以機台帳號查得該筆出金的訂單編號。印表機到位後回歸收據流程（見正本「出金」小節）。

#### 核實狀態

| 狀態 | 色標 | 說明 |
| ---- | ---- | ---- |
| 待核實 | 藍色 | 交易已完成，現金尚未確認交付。**待核實的洗分**以醒目色標提示（現金可能未交付或現場漏登記）；待核實的出金屬正常（收據不設兌現時效，玩家隔幾天才來兌現很常見） |
| 已核實 | 綠色 | 現金已交付並完成登記；出金即「已兌現」。**核實當下**該筆累計進該機台帳號於會員列表的「提款次數」「提款金額」（2026-09-04 定案） |
| 已作廢 | 灰色 | 僅出金：收據經人工作廢，不再兌付 |

#### 紀錄產生規則

  - 僅交易狀態為「已完成」的機台洗分與機台出金會出現在本頁；待確認、已取消、已逾時、未成立的交易**不會出現**。⚠️ 機台畫面顯示失敗、本頁又查無該筆時，代表交易可能沒有完成——請先到「機台交易紀錄」查明狀態再決定付不付錢，**不要憑本頁有沒有紀錄以外的印象判斷**
  - 開分與入金不需核實，不會出現在本頁（兩者都不是付錢給玩家）

### 操作

**核實（洗分）**

店員當場付現後的登記流程：

1. 依機台帳號（會員編號）或交易時間找到該筆待核實洗分，點擊「核實」
2. 確認彈窗顯示機台帳號、實際金額與交易時間，**核對無誤後**點擊確認
3. 系統標記為「已核實」，並記錄核實人員與時間

**核實（出金＝核銷收據）**

玩家持收據到櫃檯時的標準流程：

1. 於頁面上方輸入收據上的訂單編號查詢（過渡期無印表機時，為玩家出示的結算結果畫面照片上的訂單編號），或直接在列表點擊「核實」
2. 確認彈窗顯示訂單編號、機台帳號、金額與收據印出時間，**核對無誤後**點擊確認
3. 系統標記為「已核實」，並記錄核實人員與時間
4. 櫃檯付現金給玩家

| 項目 | 規則 |
| ---- | ---- |
| 可核實的狀態 | 僅「待核實」；已核實或已作廢的紀錄再次核實時，系統阻擋並提示，**避免重複付款** |
| 權限 | Admin、站長、操作員皆可執行（操作員限自身場館） |
| 連動 | 核實結果回寫機台交易紀錄的「核實狀態」「核實人員／時間」欄位；並於核實當下把該筆累計進該機台帳號於會員列表的「提款次數」「提款金額」（金額以站台核心貨幣原值累計、不換算 USDT；待核實與已作廢不計） |
| **不可撤銷** | ⚠️ **核實一經確認即無法撤銷**，誤按無法回復，只能透過後台操作紀錄追溯執行人員與時間。因此操作前務必核對彈窗內容 |

**作廢（僅出金）**

  - 僅 Admin 與站長可執行，須填寫作廢原因（必填）；用於收據遺失、爭議或確認不再兌付的情況
  - ⚠️ 作廢後不可復原，分數也不會退回機台

> ⚠️ **核實不等於付錢，是付錢之後的登記。** 現場的正確順序是：交易成功 → 現金交給玩家 → 到本頁核實。

> 洗分長時間停留在「待核實」，代表現金可能還沒交給玩家、或現場忘了登記，場館日結報表會把待核實洗分獨立計算。**出金停在「待核實」則屬正常**——收據不設兌現時效，該金額對應報表的「未兌現金額」。

> 收據**不設兌現時效、不自動作廢**。待核實的出金（未兌現收據）永久有效，一律由人工判斷後以「作廢」處理。因此日結報表的「未兌現金額」會長期累積，該金額代表場館端尚未付出的負債。

### 收據兌現的櫃檯流程（抽錄自正本「出金」小節）

玩家按下前台遊戲畫面上的**結算**鍵（廠商 API 文件稱 CASHOUT，非機櫃上的實體按鈕），平台核算可出金額後，機台印出一張收據。**機台把收據交給印表機（送入列印佇列）之後，分數才會扣除。**

  - **出金一律是全額且清空餘額**，沒有指定金額的選項，也**不套門檻取整**（2026-09-01 定案，見正本）：餘額 321 → 收據面額 **321**，機台餘額歸 **0**；收據面額可能含零頭，櫃檯付現須付至個位數
  - 收據上會印出**訂單編號**，玩家持收據到櫃檯，櫃檯依此編號查詢並付現（見「操作」的核實（出金＝核銷收據）：輸入訂單編號查核 → 核對無誤後核實 → 付現，核實即核銷）
  - 印表機或機台**嚴重損毀、收據確定印不出來**時，由櫃檯執行**人工出金**（無收據出金），並一併取消該機台尚未完成的出金交易
  - ⚠️ **若櫃檯直接對機台帳號做人工出金，系統會同時取消該機台尚未完成的出金**，避免同一筆錢被領兩次

### 相關業務規則（抽錄自正本「業務規則與驗證」）

| 項目 | 規則 |
| ---- | ---- |
| 交易核實 | 洗分與出金完成時，系統自動於「洗分出金核實」頁產生一筆**待核實**紀錄；現金交付後於該頁轉為已核實（出金的核實即收據核銷），**機台交易紀錄不提供核實操作**。僅「已完成」的交易產生核實紀錄，已核實者不可重複核實。核實與否**不影響分數與交易狀態**；**核實當下**該筆累計進會員列表的「提款次數」「提款金額」（金額以站台核心貨幣原值累計、不換算 USDT；待核實與已作廢不計；2026-09-04 定案），此外僅供對帳與稽核 |
| 核實不可撤銷 | ⚠️ 核實與作廢**一經確認皆無法撤銷**，誤操作無法回復，僅能透過後台操作紀錄追溯執行人員與時間 |
| 收據核銷 | 出金紀錄只有「待核實」狀態可核實（核銷）；重複核實阻擋並提示 |
| 現金淨收計算 | 只計入**已核實**的洗分；待核實洗分不扣除 |
| 人工出金連動 | 櫃檯對機台帳號人工出金時，必須同時取消該機台尚未完成的出金 |
