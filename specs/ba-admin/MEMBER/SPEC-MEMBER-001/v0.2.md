## 二、會員與加盟商

### 2.1 會員列表

**功能路徑：** 會員與加盟商 \> 會員列表

#### 功能說明

會員列表提供後台人員查詢、瀏覽與管理所有前台會員帳號。支援多條件篩選快速定位特定會員，並可進入個別會員的詳情頁進行進階操作。

> 📷 **【附圖】** 會員列表頁面（含篩選器與列表欄位）

![會員列表頁面](../assets/02_會員列表頁面.png)

#### 2.1.1 頁面頂部功能

頁面右上角提供三個快捷按鈕。

**OTP 報表**

查詢特定月份的 OTP 使用次數。

操作步驟： 1. 點擊「OTP 報表」按鈕，開啟彈窗 2. 輸入欲查詢的年份與月份 3. 點擊「搜尋」查看結果 4. 點擊 ✕ 關閉彈窗

**站台報表 / 使用者報表**

點擊後另開新分頁，連結至對應的 Google Sheet。

#### 2.1.2 篩選器

支援以下條件的多組合篩選，設定後點擊「搜尋」執行，點擊「清除」重置所有條件。KYC 階段與 KYC 狀態可組合使用，例如：篩選「身分證明文件驗證」階段中狀態為「審核中」的所有會員。

| 篩選欄位      | 類型              | 說明                                                                     |
| --------- | --------------- | ---------------------------------------------------------------------- |
| 會員編號      | 文字輸入            | 系統自動產生的會員唯一識別碼；支援同時查詢多筆，以「,」分隔                                         |
| 電子信箱      | 文字輸入            | 支援模糊搜尋；同時查詢多筆時以「,」分隔                                                   |
| 電話號碼      | 文字輸入            | 支援模糊搜尋；完整搜尋需包含國碼                                                       |
| KYC 階段    | 下拉選單            | 個人基本資訊驗證 / 身分證明文件驗證 / 身分證件自拍驗證 / 居住地址驗證 / 資產證明；需先選擇 KYC 階段，才可篩選 KYC 狀態 |
| KYC 狀態    | 下拉選單            | 已核准 / 審核中 / 待補件 / 未申請；須搭配 KYC 階段使用                                     |
| 會員等級      | 下拉選單            | 依平台設定的會員等級進行篩選                                                         |

| 註冊日期      | 日期範圍            | 可透過日曆選取或手動輸入時間區間                                                       |
| 月有效投注額    | 範圍輸入（min ～ max） | 單位 USDT                                                                |
| 月損益量      | 範圍輸入（min ～ max） | 單位 USDT                                                                |
| 存款次數      | 範圍輸入（min ～ max） | 僅計系統入金，不含人工入金                                                             |
| 存款金額      | 範圍輸入（min ～ max） | 僅計系統入金，不含人工入金，單位 USDT                                                     |
| 提款次數      | 範圍輸入（min ～ max） | 僅計系統出金，不含人工出金                                                             |

**會員啟用狀態**

顯示該會員目前的帳號狀態，分為「啟用」與「停用」兩種。處於停用狀態的會員將無法登入或進入平台。點擊鉛筆圖示可切換狀態。

**KYC 狀態**

顯示五個 KYC 驗證階段的審核狀態，後台人員可在此執行審核操作：

  - 審核結果選擇「通過」或「駁回」；選擇駁回時，需從下拉選單選取駁回原因
  - 操作完成後點擊右上角「儲存」確認，或點擊「取消」放棄變更

> ⚠️ 未開放審核的階段（顯示 --）不可操作。

站台可同時開啟多個幣別的錢包。會員的餘額類欄位預設為**收合**狀態，只顯示該站台**核心貨幣**錢包的金額；當站台開啟一種以上幣別時，欄位右側顯示展開箭頭，點擊後逐列列出各幣別錢包的金額，再次點擊收合。

**適用欄位：**

| 位置                    | 欄位                                      |
| --------------------- | --------------------------------------- |
| 2.1.3 會員列表            | 帳戶餘額（主錢包）                               |
| 2.1.4 側邊簡易資料面板〈帳戶資訊〉  | 帳戶餘額（主錢包）、提領所需有效投注額（流水錢包）、可提領餘額         |
| 2.1.5 會員詳細資料頁〈帳務資訊〉   | 帳戶餘額（主錢包）、提領所需有效投注額（流水錢包）、可提領餘額         |

**顯示規則：**

| 規則        | 說明                                                                                                          |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| 幣別清單來源    | 依「帳務管理 \> 鏈上錢包管理」中狀態為**啟用**的幣種為準（含法幣頁籤的幣別）；狀態為關閉或禁用的幣種不列出。幣種增減隨鏈上錢包管理的啟用狀態連動，本頁不另行設定 |
| 展開箭頭顯示條件  | 已啟用幣種**超過一種**時才顯示展開箭頭；僅啟用一種幣別的站台不顯示箭頭，維持單行呈現                                                                |
| 收合時顯示的數值  | 該站台**核心貨幣**錢包的餘額——**不做匯率換算，也不是各幣別的加總**。核心貨幣為主站台層級的設定，底下子站台一律繼承、不可各自指定                                       |
| 展開後的排列順序  | 核心貨幣固定列於第一列，其餘已啟用幣種依鏈上錢包管理的幣種順序接續排列；每列顯示「幣種代碼 ＋ 金額」                                                          |
| 金額為 0 的幣別 | 仍列出並顯示 0.00，不因無餘額而隱藏                                                                                         |
| 展開狀態的保留   | 逐欄各自獨立展開／收合，僅作用於當次瀏覽；換頁、重新查詢或重新進入頁面後回到收合預設                                                                   |

### 2.2 加盟列表

**功能路徑：** 會員與加盟商 \> 加盟列表

#### 功能說明

顯示平台所有具加盟商身分的會員，供後台人員查詢、篩選與管理加盟商狀態及相關設定。

> 📷 **【附圖】** 加盟列表頁面

![加盟列表頁面](../assets/07_加盟列表頁面.png)

#### 2.2.1 篩選器

| 篩選欄位 | 類型   | 說明                                     |
| ---- | ---- | -------------------------------------- |
| 會員編號 | 文字輸入 | 支援同時查詢多筆，以「,」分隔                        |
| 狀態   | 下拉選單 | 全部 / 啟用 / 停用；啟用表示該會員具加盟商身分，停用表示不具加盟商身分 |

設定後點擊「搜尋」執行，點擊「清除」重置所有條件。

#### 2.2.2 加盟列表

列表右上角顯示總筆數與當前頁碼，可切換頁面。

  - 點擊**狀態 Toggle**：切換該加盟商的啟用或停用狀態
  - 點擊**超級加盟商按鈕**：進入 Inline 編輯模式（詳見 2.2.3）

| 欄位    | 說明                                                                                                                                                                                                                                                                                                 |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 會員編號  | 加盟商會員的唯一識別碼；暱稱顯示於編號下方（若有）                                                                                                                                                                                                                                                                          |
| 狀態    | 顯示該會員目前是否為啟用中的加盟商身分；點擊可切換啟用或停用                                                                                                                                                                                                                                                                     |
| 加盟等級  | 顯示加盟商所屬等級，依平台設定對應不同等級與分潤規則。分為兩種類型：**一般加盟商（全民加盟）** 顯示於左側，以 Badge 呈現會員目前達成的 Partner 等級（如 Partner 1），共三種狀態：（1）**已申請**（白底）：會員達成升等門檻，且已透過前台主動申請成為加盟商；（2）**達成未申請**（深灰底）：會員已達成升等門檻，但尚未透過前台申請；（3）**未達成**（黑底）：會員尚未達成升等門檻。**客製化加盟商（S Partner）** 顯示於右側，名稱可於加盟商設定頁自訂；點擊按鈕後該列進入 Inline 編輯模式，可直接修改各項數值（詳見 2.2.3） |
| 佣金比例% | 加盟商與平台針對下線於該結算週期之損益進行分潤的最高比例（加盟商可於前台自行調整實際套用比例）                                                                                                                                                                                                                                                    |
| 優惠%   | 加盟商與平台針對下線所領取之優惠獎勵進行分潤的比例                                                                                                                                                                                                                                                                          |
| 返水%   | 加盟商與平台針對下線所領取之返水獎勵進行分潤的比例                                                                                                                                                                                                                                                                          |
| 推薦返傭% | 加盟商與平台針對下線所產生之推薦返傭獎勵進行分潤的比例                                                                                                                                                                                                                                                                        |
| $行政費  | 加盟商領取佣金時需扣除的手續費用（單位 USDT）                                                                                                                                                                                                                                                                          |
| x稽核   | 加盟佣金計算完成後，加盟商申請提領時所需完成的可提領投注倍數                                                                                                                                                                                                                                                                     |
| 更新時間  | 該筆加盟商資料最後一次異動的時間                                                                                                                                                                                                                                                                                   |
| 操作人員  | 最後更新或操作該筆加盟商資料的後台人員編號                                                                                                                                                                                                                                                                              |

#### 2.2.3 客製化加盟商設定

操作步驟： 1. 於列表中找到目標加盟商會員 2. 點擊「加盟等級」欄位右側的「超級加盟商」按鈕（名稱可於加盟商設定頁自訂） 3. 該列的佣金比例%、優惠%、返水%、推薦返傭%、行政費、稽核欄位進入 Inline 編輯模式 4. 直接修改各欄位數值 5. 點擊列尾的 ✓ 確認儲存；或點擊 ✕ 取消並還原原始值

### 2.4 推薦註冊金設定

**功能路徑：** 會員與加盟商 \> 推薦註冊金設定

#### 功能說明

設定特定會員的推薦註冊金方案。每位會員由系統自動產生唯一的推薦碼，新會員透過該推薦碼註冊後可獲得對應的註冊金獎勵。

#### 2.4.1 篩選器

| 篩選欄位 | 類型   | 說明              |
| ---- | ---- | --------------- |
| 會員編號 | 文字輸入 | 支援同時查詢多筆，以「,」分隔 |

設定後點擊「搜尋」執行，點擊「清除」重置條件。

#### 2.4.2 新增設定

操作步驟： 1. 點擊列表左上角「新增」 2. 於彈窗中輸入會員編號（必填） 3. 點擊「新增」；系統自動帶入該會員的推薦碼並顯示於列表

> ⚠️ 會員編號為必填，不可為空。

#### 2.4.3 列表欄位

| 欄位    | 說明                                          |
| ----- | ------------------------------------------- |
| 會員編號  | 已設定推薦註冊金方案的會員                               |
| 推薦碼   | 系統為該會員自動產生的唯一推薦碼；點擊旁側複製圖示可複製推薦碼             |
| 推薦註冊金 | 透過該推薦碼註冊的新會員可獲得的註冊金金額（單位 USDT）              |
| 稽核倍數  | 註冊金的可提領投注倍數                                 |
| 建立時間  | 該筆設定的建立時間；點擊旁側刪除圖示後，彈出確認視窗，確認後刪除該筆設定，操作不可復原 |

**編輯推薦註冊金**

點擊推薦註冊金旁的編輯圖示，推薦註冊金與稽核倍數欄位同時進入 Inline 編輯模式，修改後點擊「儲存」確認，或點擊「取消」還原。

### 2.5 暱稱禁用詞設定

**功能路徑：** 會員與加盟商 \> 暱稱禁用詞設定

#### 功能說明

設定會員暱稱的禁用詞清單，分為四個類別分頁管理。會員在前台設定暱稱時，若包含禁用詞則無法通過。

#### 2.5.1 分頁說明

| 分頁          | 說明      |
| ----------- | ------- |
| Violence    | 暴力相關禁用詞 |
| Pornography | 色情相關禁用詞 |
| Sensitive   | 敏感詞彙    |
| Other       | 其他類禁用詞  |

各分頁的操作方式相同，設定互相獨立。

#### 2.5.2 新增禁用詞

操作步驟： 1. 切換至目標分頁 2. 在輸入框中輸入禁用詞，按 Enter 確認 3. 詞彙以 Tag 形式顯示於輸入框內，可持續新增多筆

#### 2.5.3 移除禁用詞

點擊 Tag 右側的 ✕ 即可移除該禁用詞。
