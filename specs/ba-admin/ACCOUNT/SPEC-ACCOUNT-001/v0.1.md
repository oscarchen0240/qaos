### 功能說明

在會員列表新增「創建會員帳號」按鈕，讓後台直接建立會員帳號。會員紀錄新增「帳號類型」欄位區分兩種帳號，**不另外建立一套帳號系統**：

| 帳號類型 | 說明 |
| ------- | ---- |
| 線上 | 現行所有前台註冊會員，行為完全不變（預設值）。**前台維持開放以帳號密碼方式自行註冊新帳號**（註冊時強制綁定電子信箱），與後台「創建會員帳號」並行為兩條建立途徑 |
| 機台 | 綁定一台實體機台的共用帳號，由後台建立；系統生成的帳號密碼可登入前台，但**僅供機台本身使用、不交付玩家**（前台註冊產生的一律是線上帳號，與此無關） |

本按鈕是實體機台功能「新增機台帳號」的唯一入口：帳號類型選「機台」時，一併建立機台帳號與機台資料。

### 操作

#### 創建會員帳號

點擊會員列表的「**創建會員帳號**」按鈕開啟 Modal。**帳號一律建立於目前所在的站台底下**（機台主站台自行經營時，機台帳號即建立於主站台自身之下），不提供跨站台指定——機台帳號的所屬場館即目前所在的機台場館，Modal **不設「所屬場館」欄位**（「目前站台」即後台各頁皆有的**站台切換下拉選單**所選站台：選單列出操作者有權限的站台，頁面內容一律以其為範圍，故會員列表也不需「所屬站台」欄位）。**登入帳號與密碼不需輸入——線上與機台兩種帳號類型統一由系統自動生成，且皆可用於前台登入**：

| 欄位名稱 | 必填 | 說明 |
| ------- | ---- | ---- |
| 帳號類型 | 必填 | 線上／機台；**預設值依目前站台的「站台類型」帶入**——機台場館預設「機台」、線上站台預設「線上」。「機台」選項**僅於目前站台為機台場館時可選**（線上站台下停用——機台帳號必屬某一機台場館，而帳號只會建立在目前站台底下）。選「機台」時帶出以下欄位 |
| 機台名稱 | 選填 | **即該會員帳號的「暱稱」欄位**——與線上會員的暱稱為同一欄位，不另設機台專屬欄位（2026-09-03 定案），會員列表照常顯示於會員編號下方。供後台辨識，例如「A 區 03 號」。機台不另設機台編號，識別碼即本次建立的會員編號。後台建立／修改不經「暱稱禁用詞」檢查（該檢查僅作用於前台設定暱稱，機台場館亦不顯示該設定頁）|
| 機台狀態 | 不顯示 | 預設建立為「**啟用**」——憑證未寫入機台前機台本來就無法連線，不需先停用再手動啟用；如需暫停於會員詳細頁「機台資訊」區塊停用 |

**帳號類型選「線上」時不帶額外欄位**：建立一名所屬目前站台的線上會員（電子信箱與電話留空），建立後的行為與前台註冊會員完全相同。後台創建並非線上會員唯一的建立途徑——**前台仍開放玩家以帳號密碼方式自行註冊新帳號**，兩條途徑並行：前台註冊的帳號密碼由玩家於註冊時自訂、不經系統生成，且**註冊時強制綁定電子信箱**；密碼遺失可自行走前台「忘記密碼」機制（見下方「前台忘記密碼」），後台亦可於會員詳細頁「重設密碼」代為處理（見下方「重設密碼」），兩者並行。

額度上限不在此設定——一律套用**所屬場館的場館設定值**（場館層級，見站台列表 v04／開發包②）；洗分門檻於機台端設定，後台不設。

點擊「建立」後，系統建立帳號（餘額為 0，即本次創建的會員帳號）；帳號類型「機台」同時建立機台資料，一個帳號只對應一台機台。建立成功畫面**完整顯示一次**系統生成的登入帳號與密碼，並提供複製按鈕；關閉後不再完整顯示，密碼遺失以「重設密碼」處理（見下方）。**憑證不隨建立產生**——於該帳號的會員詳細頁面生成（見下方「機台憑證」）。

> 📖 **機台帳號的帳密用途**：機台的**前台遊戲畫面**即以此帳密登入平台，由現場人員設定機台時輸入，**不交付玩家**。機台憑證則供機台主控程式與平台 API 通訊，兩者各自獨立、互不影響（見下方「機台憑證」）。

#### 機台資訊區塊（會員詳細頁）

機台**不設獨立管理頁**——機台帳號照常列於會員列表，查機台就用會員列表既有的篩選（帳號類型選「機台」、所屬站台選場館、會員編號即機台帳號）；單一機台的檢視與管理集中在該帳號的**會員詳細頁**，詳細頁新增「**機台資訊**」區塊（機台憑證另為獨立區塊，見下方「機台憑證」）：

| 欄位 | 說明 |
| ---- | ---- |
| 機台名稱 | 即該帳號的「暱稱」欄位（與線上會員同一欄位）；供後台辨識，例如「A 區 03 號」；可修改，修改即更新該帳號的暱稱 |
| 所屬場館 | 場館名稱與站台代碼；唯讀，可點擊回到站台列表該層 |
| 機台狀態 | 啟用 / 停用，Badge 色標呈現 |
| 進行中場次 | 該機台目前進行中的場次摘要（場次屬開發包③）；無進行中場次時顯示「—」——**開發包③金流上線前恆為「—」** |
| 時間紀錄 | 機台資料的建立時間、修改時間（UTC+0），不開放編輯 |

分數餘額即該帳號的主錢包餘額（詳細頁原有欄位），不在本區塊重複呈現。

#### 編輯機台

於「機台資訊」區塊點擊「編輯」：

| 欄位名稱 | 可否修改 | 說明 |
| ------- | ------- | ---- |
| 所屬場館 | 不可 | 唯讀；如需搬移須停用本機台後另建新機台帳號 |
| 機台名稱 | 可 | 即會員暱稱，修改即更新該帳號的暱稱 |
| 機台狀態 | 可 | 啟用 / 停用 |

機台與帳號的綁定不可更換（一對一，見「業務規則」）。點擊「儲存變更」後，修改時間自動更新。

#### 重設密碼

後台建立的帳號，系統生成的密碼僅於建立成功時完整顯示一次，之後無法查看。會員密碼遺失或外洩時（不論帳號由後台建立或前台註冊），於該帳號的**會員詳細頁**點擊「重設密碼」，二次確認後系統生成新密碼，**連同登入帳號一併完整顯示一次**（各附複製按鈕；現場人員須以成對的帳號密碼重新登入，僅顯示密碼不足以操作），舊密碼立即失效。

  - 適用對象：**所有會員帳號**——後台建立與前台註冊、線上與機台皆適用。前台註冊會員另可自行走前台「忘記密碼」機制（見下方），兩者並行——會員自己忘記密碼走前台，找上客服或站務時由後台代為重設
  - ⚠️ **機台帳號重設密碼後，機台的前台遊戲畫面將無法再以舊密碼登入**，須由現場人員以新帳密重新登入機台——比照重置憑證，非必要不要重設，重設前先與現場確認（機台對接 API 屬開發包③、機台尚未實際連線，實際影響自該包上線起）

#### 前台忘記密碼（線上會員）

> 📖 本項為**前台功能**，超出後台手冊的原有範圍；因帳號建立與密碼規則已於本檔定義，一併在此定案供前台開發引用。

前台登入頁提供「忘記密碼」入口，流程如下：

1. 會員輸入**帳號與綁定的電子信箱**
2. 兩者相符時，系統寄送**重設密碼連結**至該信箱；連結具時效（**預設 1 小時**），逾時失效須重新申請，重新申請會使先前尚未使用的連結失效
3. 會員點擊連結設定新密碼，完成後**舊密碼立即失效**

| 項目 | 規則 |
| ---- | ---- |
| 適用對象 | 已綁定電子信箱的線上會員，不論由前台註冊或後台建立 |
| 不提示帳號存在 | 查無帳號或信箱不符時，前台一律顯示「若資料相符，重設連結已寄出」，不提示帳號是否存在，避免被用於探測帳號 |
| 機台帳號 | 不適用——機台帳號沒有電子信箱，帳密由後台管理，遺失一律走後台「重設密碼」 |
| 未綁定信箱的帳號 | 無法使用本機制，一律以後台「重設密碼」處理。**前台註冊強制綁定電子信箱**，故未綁定信箱的帳號只會是後台建立者（建立時信箱留空且尚未補綁） |
| 與後台重設密碼的關係 | 兩者獨立、互不影響；後台「重設密碼」適用所有會員帳號（含前台註冊），本機制供已綁定信箱的會員自行操作，兩者並行 |

#### 機台憑證

機台憑證是機台連線平台的身分證明，由後台產生後寫入機台。**生成與管理位於該機台帳號的「會員詳細頁面」**——機台帳號的詳細頁多一個「機台憑證」區塊，提供「產生憑證」與「重置憑證」：

  - 憑證內容**只在產生與重置時完整顯示一次**，並提供複製按鈕；之後只顯示前後各 4 碼，中間以遮罩呈現
  - 一台機台同時只有一組有效憑證
  - 點擊「重置憑證」須二次確認；確認後舊憑證立即失效
  - 區塊內顯示憑證建立時間與最後使用時間；尚未產生憑證時顯示「產生憑證」按鈕
  - 憑證格式為 **JWT（JSON Web Token）**（2026-09-03 定案），由平台簽發、機台每次呼叫平台 API 時附帶。字串長達數百字元，一次性顯示畫面須提供複製按鈕並允許換行完整顯示；遮罩顯示沿用前後各 4 碼
  - **重置即失效由平台端保證**：JWT 本身無法被收回，平台驗證憑證時除簽章外須比對該機台目前有效的憑證識別（如 jti 或憑證版本號），舊憑證即使簽章仍有效亦一律拒絕
  - 憑證**不設有效期限**（v07 定案）：設期限就必須定義到期前的換發流程，現場逐台重寫憑證的成本過高；憑證一經簽發長期有效，**僅靠「重置憑證」使舊憑證失效**

> 📖 **機台憑證與登入帳密是兩回事**：憑證供機台主控程式（Kernel）與平台 API 通訊；帳密供機台的前台遊戲畫面登入。重置憑證不影響帳密，重設密碼也不影響憑證。

> ⚠️ 重置憑證會讓機台**立即無法運作**，必須由現場人員把新憑證寫入機台後才會恢復。非必要不要重置，重置前請先與現場確認。（機台對接 API 屬開發包③、機台尚未實際連線，本警告自該包上線起生效；在此之前驗證憑證的 API 尚不存在，憑證僅為預先發放）

#### 停用／啟用機台

於「機台資訊」區塊操作（或編輯時切換機台狀態）。停用後該機台立即無法運作，玩家無法投鈔、遊玩或出金；再次啟用即恢復運作（機台實際運作自開發包③對接 API 上線起）。停用**不會**影響機台帳號上的餘額。

機台**不提供刪除操作**，只能停用：

  - 機台報廢或不再使用時，一律以**停用**處理；機台資料與機台帳號都會保留，供歷史紀錄查詢
  - 停用可再啟用；如需搬移場館，一律停用本機台後另建新機台帳號

#### 機台帳號的特性

| 項目 | 規則 |
| ---- | ---- |
| 會員編號 | 沿用系統既有的會員編號產生規則 |
| 所屬站台 | 固定為該機台所在的場館站台（場館子站台，或自行直接經營的機台主站台） |
| 建立方式 | 由後台建立，不經前台註冊；沒有電子信箱、沒有電話號碼；登入帳號與密碼由系統自動生成（與線上帳號的後台建立**統一**） |
| 登入 | 可以系統生成的帳號密碼登入前台，**僅供機台本身的前台遊戲畫面登入使用**——帳密由現場人員設定機台時輸入，不交付玩家 |
| 錢包 | 使用主錢包，即機台上顯示的分數 |
| 幣別 | 取自所屬主站台的核心貨幣，不可修改 |

### 會員列表的同步修訂（與本按鈕同批上線）

機台帳號一旦存在資料庫，既有會員功能就會自動對它生效，下列修訂**必須與創建功能同批上線**，否則後台無從區分兩種帳號類型：

| 章節 | 修訂內容 |
| ---- | ------- |
| 2.1.2 篩選器 | 新增「帳號類型」篩選（全部／線上／機台），預設為「全部」 |
| 2.1.3 會員列表 | 機台帳號照常列出，不預設排除；總會員數（總筆數）依篩選結果計算。**存款次數／存款金額累計機台開分與機台入金**（不需核實，交易完成當下直接累計）、**提款次數／提款金額累計已核實的機台洗分與機台出金**（於「洗分出金核實」頁核實當下累計，待核實與已作廢不計）；金額一律以站台核心貨幣原值累計、不換算 USDT（2026-09-04 定案，金流屬開發包③⑤） |
| 2.1.5 會員詳細資料頁 | 機台帳號的詳細頁可開啟，但 KYC、等級、優惠、邀請鏈區塊隱藏；**新增「機台資訊」與「機台憑證」兩個區塊**（見上方「機台資訊區塊」「機台憑證」）。**所有會員帳號（含前台註冊）新增「重設密碼」操作**（見上方「重設密碼」） |
| 2.1.6 多幣別錢包展開顯示 | 會員列表、側邊簡易資料面板與詳細頁的餘額欄（帳戶餘額（主錢包）／提領所需有效投注額（流水錢包）／可提領餘額）在站台啟用一種以上幣別時可展開逐列檢視各幣別（規格見 `會員與加盟商_spec_v02.md` 2.1.6）。**機台場館的核心貨幣為 TWD、鏈上錢包管理僅顯示法幣 TWD 一個頁籤，只啟用這一種幣別，故機台帳號的餘額欄不顯示展開箭頭、維持單行呈現**；收合值即該帳號的主錢包（TWD）餘額，也就是機台上顯示的分數。**本包不需為此另做處理**；未來場館若啟用第二種幣別，展開行為依 2.1.6 自動適用 |

### 業務規則與驗證（本包適用）

| 項目 | 規則 |
| ---- | ---- |
| 機台識別 | 機台不另設機台編號，一律以其機台帳號的會員編號識別 |
| 帳號一對一 | 一個機台帳號只能綁定一台機台；機台帳號與機台資料由「創建會員帳號」一併建立，不提供將既有帳號另行綁定機台 |
| 建立站台歸屬 | 「創建會員帳號」建立的帳號一律歸屬**操作當下所在的站台**（＝頁面站台切換下拉選單所選站台，後台各頁皆有、列出操作者有權限的站台），不提供跨站台指定（Modal 不設「所屬場館」欄位）；機台帳號的所屬場館即目前所在的機台場館（含自行經營的機台主站台），「機台」選項僅於機台場館可選，建立後所屬站台不可修改 |
| 建立預設啟用 | 機台預設建立為「啟用」——憑證未產生／寫入前機台無法連線平台，且機台對接 API（開分／洗分／入金／出金）屬開發包③，該包上線前不會產生任何金流 |
| 憑證唯一性 | 一台機台同時只有一組有效憑證；重置後舊憑證立即失效。憑證內容僅於產生與重置時完整顯示一次。憑證為 JWT（2026-09-03 定案），重置即失效須由平台端比對現行憑證識別保證，不能只驗簽章；**不設有效期限**（v07 定案） |
| 機台停用 | 停用中的機台無法運作；停用不影響機台帳號上的餘額 |
| 機台不可刪除 | 機台與機台帳號不提供刪除操作；報廢或不再使用一律以停用處理，資料保留供歷史紀錄查詢 |
| 帳號密碼生成 | 「創建會員帳號」不論帳號類型（線上／機台），登入帳號與密碼一律由系統自動生成、**可用於前台登入**；建立成功時完整顯示一次並提供複製，之後不再完整顯示 |
| 前台自行註冊 | 前台維持開放以帳號密碼方式自行註冊，僅產生線上帳號；帳號密碼由玩家於註冊時自訂、不經系統生成，**註冊時強制綁定電子信箱**；密碼遺失走前台「忘記密碼」（不適用後台「重設密碼」） |
| 前台忘記密碼 | 已綁定電子信箱的線上會員可於前台申請重設：寄送具時效的重設連結（預設 1 小時，重新申請使舊連結失效），完成後舊密碼立即失效；查無帳號或信箱不符時前台不提示帳號是否存在。機台帳號與未綁定信箱的後台建立帳號不適用，一律走後台「重設密碼」 |
| 機台帳號登入 | 機台帳號的帳密僅供機台本身的前台遊戲畫面登入使用，由現場人員設定機台時輸入，**不交付玩家** |
| 重設密碼 | **所有會員帳號**（後台建立與前台註冊、線上與機台）皆可於會員詳細頁重設密碼，新密碼**連同登入帳號**僅於重設當下完整顯示一次，舊密碼立即失效 |
| 幣別 | 建立時取自所屬主站台的核心貨幣，建立後不可修改 |
| 時區 | 後台所有時間欄位一律顯示為 UTC+0 |
