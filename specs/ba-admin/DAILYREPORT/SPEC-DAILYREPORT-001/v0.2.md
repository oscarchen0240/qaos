## 場館日結報表（內部，未對客戶開放）

> ⚠️ **內部章節**：本功能尚未對客戶開放。本檔首行帶 `<!-- INTERNAL -->` 標記，`build_manual.sh` 產出客戶版手冊時會自動略過；`build_skill.sh` 與 Claude Code 端仍完整包含。正式對客戶開放後，請併入 `各式報表_spec_vNN.md` 並移除本檔標記。

> 📦 **拆包說明**：本檔為實體機台功能的**開發包⑤（場館日結報表——各式報表新增頁）**，自正本 `實體機台_spec_v07.md` 抽錄；**重疊部分如有出入一律以正本為準**，並回報修正本檔。本包**相依開發包③**（`機台金流與場次_spec_v01.md`）的交易與場次資料模型——四種金流（開分／洗分／入金／出金）、場次引擎與日結結算皆定義於該包，本報表為其之上的統計檢視。核實狀態（已核實／待核實、已兌現／未兌現）由開發包⑤之一「洗分出金核實」的操作回寫。

**功能路徑：** 各式報表 \> 場館日結報表

**互動原型：** `protos/場館日結報表_proto_v01.html`（僅供開發團隊理解需求，不交付客戶）

**規格版本：** v01（2026-08-21，自實體機台 spec v05 抽錄成包）

-----

### 功能說明

結算各場館與各機台的現金收支，供平台與場館對帳、分潤。營業日的切分依場館設定的「日結時間」；除逐日檢視外，可依週、月或自訂區間彙總計算。

**權限**（沿用正本「角色與權限」）：

| 功能項目 | 管理員 | 站長 | 操作員 |
| ------- | ----- | ---- | ------ |
| 場館日結報表 | 管轄範圍 | 管轄範圍 | 自身場館 |

### 篩選器

頁面資料範圍跟隨頁面標題下方的站台切換下拉選單（後台各頁皆有，一次僅顯示所選站台），不另設場館篩選欄位。

| 篩選欄位 | 類型 | 說明 |
| ------- | ---- | ---- |
| 機台帳號 | 文字輸入 | 輸入會員編號；留空為場館全部機台 |
| 結算日期 | 日期範圍 | 必填；不設區間上限，與手冊其他報表一致 |
| 統計週期 | 下拉選單 | 按日（預設）／按週／按月／區間合計。按週以週一為週起；非按日時，每列為該週期內各營業日的彙總 |
| 統計維度 | 下拉選單 | 依場館彙總 / 依機台明細 / 依場次明細；「依場次明細」時統計週期僅決定查詢範圍，列表仍逐場次列出、不彙總 |

### 列表欄位

| 欄位 | 說明 |
| ---- | ---- |
| 結算期間 | 按日顯示營業日（依場館日結時間切分）；按週／按月／區間合計顯示該週期的起訖日期 |
| 場館／機台 | 依統計維度顯示至場館、機台或場次層級 |
| 場次編號 | 僅「依場次明細」維度顯示；另附開始／結束時間與場次時長 |
| 場次數 | 「依場館彙總」與「依機台明細」維度顯示，為當日結束的場次筆數：依機台明細＝該機台帳號當日的場次數；依場館彙總＝**該場館底下所有機台帳號當日場次數的加總**（2026-09-03 定案） |
| 開分金額 | 當日開分總額（店員現場收現） |
| 洗分金額 | 當日洗分總額（店員現場付現） |
| 已核實洗分 | 當日洗分中已在「洗分出金核實」頁核實的金額合計 |
| 待核實洗分 | 當日洗分中仍為待核實的金額合計；不為 0 時標示提醒，代表現金可能未交付或現場漏登記 |
| 進鈔金額 | 當日入金總額（紙鈔機收現） |
| 收據金額 | 當日出金總額（印出的收據面額合計；過渡期機台暫無印表機時，為結算結果畫面顯示的出金金額合計） |
| 已兌現金額 | 當日已核實（核銷）的收據金額合計 |
| 未兌現金額 | 截至查詢當下仍為待核實的收據金額合計 |
| 現金淨收 | 開分 ＋ 進鈔 － **已核實洗分** － 已兌現（**不扣待核實洗分**——尚未確認付出） |
| 有效投注額 | 當日該場館／機台的投注總額，以主站台核心貨幣計算（機台場館為 TWD；2026-09-03 定案） |
| 損益 | 當日投注損益，以主站台核心貨幣計算；**以機台（會員）端計算**——正值代表玩家淨贏、機台分數增加（與手冊「直推總損益／會員損益」的視角一致；平台視角另用「派彩」一詞）。正值綠色、負值紅色 |
| 期初餘額 | 該結算期間**起點**的分數合計——即前一營業日結算時點各機台的分數；無前一營業日資料時為 0。與「場次資訊」的期初餘額同義，層級為場館／機台的該期間起點（＝該期間第一場場次的期初餘額）；「依場次明細」維度即顯示該場次的期初餘額 |
| 期末餘額 | 該日結算時點各機台的分數合計 |

列表底部顯示**整個查詢結果**的各欄總計（不隨排序與分頁改變）；**「期初餘額」與「期末餘額」不加總**（見下）。頁面右上角提供「匯出 CSV」，匯出整個查詢結果、不受分頁限制。

> **「期末餘額」是時點存量，總計列不做逐列相加**（2026-09-12 定案）。逐列相加會把同一筆餘額重複計算——例如同一機台前一場次洗分後留餘數 900 結束、下一場次承接該 900 後出金清空為 0，兩列相加得 900，但結算時點該機台實際為 0。總計列一律**各機台取其查詢範圍內時間最後一個場次／最後一個營業日結算時點的期末餘額，再跨機台相加**；「依場次明細」維度查單一機台時即等於最後一列的值。CSV 匯出的總計列同規則。（原定案「最後一個場次為進行中時取最後一個已結束場次」已於 **2026-09-17 修訂**——改為**計入進行中場次累計至查詢當下的分數**，見下。）

> ⚠️ **「期初餘額」比照上述辦理**（2026-09-17 新增欄位時定案）：同為時點存量，總計列取**各機台在查詢範圍起點前一營業日結算時點的分數**（＝該機台範圍內最早場次的期初餘額），再跨機台相加。餘額以外的金額與筆數欄則照常為各列合計。各**列**的餘額同樣是時點值：依場館彙總／依機台明細的每一列，餘額涵蓋篩選條件內的所有機台，**含當期無場次但仍有留存分數者**（沿用其最近一個營業日的結算時點值），故依結算期間排序時相鄰各列前後相接——較早一期的期末餘額即次一期的期初餘額，按日檢視時總計列的期末餘額就是**最新一個營業日**那一列的值（預設排序新→舊時即第一列）。

> 欄位說明以「當日」敘述；統計週期非按日時，各金額與筆數欄為**該週期內各營業日的合計**，「期初餘額」取該週期**第一個營業日之前**結算時點的值、「期末餘額」取該週期**最後一個營業日**結算時點的值，「未兌現金額」不受週期影響、一律為截至查詢當下的累計。

> 🧮 **餘額驗算**：**期末餘額 ＝ 期初餘額 ＋ 開分金額 ＋ 進鈔金額 ＋ 損益 － 洗分金額 － 收據金額**。期初餘額為 2026-09-17 新增欄位——原先列表未顯示期初值，期末餘額無從驗算（例：期初 1,000＋入金 2,500＋開分 1,500－出金 3,500－洗分 1,000＝期末 500）。此處「損益」以**機台（會員）端**計算，正值代表玩家淨贏、機台分數增加。洗分／出金以**交易發生**為準計入（不論核實與否），故驗算與「已核實洗分」「已兌現金額」無關。**進行中場次的分數計入期末餘額**（2026-09-17 定案，修訂 2026-09-12 原「取最後一個已結束場次」的處置）：未結束的場次其分數仍實際存在於機台上，不計入會使驗算出現等於該場次淨變動的差額。故期末餘額一律取該機台**截至查詢當下**的分數，「依場次明細」維度的進行中場次列亦顯示累計至查詢當下的分數（比照「場次時長」的呈現方式，非顯示「—」），驗算式在任何查詢範圍皆成立。

> ⚠️ 「現金淨收」是**推算值**，代表場館端當日現金應該增減多少，尚未兌現的收據不算在內（那是未來要付出去的錢）。與現場實際點鈔金額的差異須由人工查核。

| 分頁列 | 列表底部顯示總筆數、當前顯示區間（第 N–M 筆）、頁碼與上一頁／下一頁；首頁與末頁時對應按鈕停用 |
| 狀態保留 | 切換頁碼保留當前篩選條件、統計維度、排序與鑽取麵包屑狀態；**變更篩選、統計週期、統計維度、排序或鑽取層級時一律回到第 1 頁** |

篩選器下方顯示當前的鑽取路徑（麵包屑），最多三層，每層下方標註其對應的統計維度：

**場館**（依場館彙總） › **結算期間**（依機台明細） › **機台帳號**（依場次明細）

| 項目 | 規則 |
| ---- | ---- |
| 層級數 | 依「統計維度」而定——依場館彙總顯示一層、依機台明細兩層、依場次明細三層；直接切換「統計維度」下拉選單時麵包屑同步更新 |
| 當前層級 | 路徑最後一層為當前檢視層級，純文字不可點 |
| 上層連結 | 其餘各層為可點連結，點擊回到該層，並**還原該層鑽取前的篩選條件**（統計維度、結算日期、機台帳號） |
| 向下鑽取 | 於「依場館彙總」列點場館名 → 切至「依機台明細」，並將**結算日期收斂為該列的結算期間**；於「依機台明細」列點機台帳號 → 切至「依場次明細」，並將該機台帳號帶入篩選器 |
| 第一層場館 | 即站台切換下拉選單所選的場館（場館範圍跟隨站台切換），故第一層僅顯示當前場館、不另提供切換 |
| 重設 | 切換站台或按「清除」時鑽取路徑重設為第一層 |

> 本麵包屑為**頁內的維度鑽取路徑**，與後台全站頁首的功能路徑麵包屑（各式報表 / 場館日結報表）並存，兩者用途不同。

### 背景：場次資訊（抽錄自正本「場次」節）

「依場次明細」維度所列的場次來自開發包③的場次引擎。簡單說：**從機台有分數開始玩起算，到洗分、出金或分數歸 0 為止，算一個場次。**

#### 場次資訊

| 欄位 | 說明 |
| ---- | ---- |
| 場次編號 | 系統產生的唯一識別碼 |
| 場館／機台 | 該場次所屬的場館與機台帳號（會員編號） |
| 場次狀態 | 進行中 / 已結束 / 逾時結束 / 日結結算 |
| 開始時間 / 結束時間 | UTC+0；進行中的場次結束時間顯示「—」 |
| 場次時長 | 開始至結束的時間差；進行中則顯示累計至查詢當下 |
| 期初餘額 | 場次開始時的分數（開分／入金起始者為 0；承接洗分餘數或日結結算轉入者為承接金額；出金一律清空餘額、無餘數承接） |
| 開分 / 入金金額 | 期間各自的總額 |
| 洗分 / 出金金額 | 期間各自的總額 |
| 投注筆數 | 期間產生的注單數 |
| 有效投注額 | 期間的有效投注總額，以主站台核心貨幣計算（機台場館為 TWD） |
| 損益 | 期間的投注損益，以主站台核心貨幣計算；正值綠色、負值紅色 |
| 期末餘額 | 場次結束時的分數（歸零結束與出金結束為 0；洗分結束留有餘數時為該餘數）；**進行中場次顯示累計至查詢當下的分數**（2026-09-17 定案，比照「場次時長」） |

場次不另設獨立頁面，於下列位置呈現：

  - **機台前台：** 注單與遊戲紀錄僅顯示當前進行中場次的內容；無進行中場次時為空
  - **會員詳細頁「機台資訊」區塊：** 顯示該機台目前進行中的場次摘要
  - **機台交易紀錄：** 可依場次編號篩選，列表顯示所屬場次
  - **場館日結報表：** 統計維度可選「依場次明細」

### 業務規則與驗證（本包相關條目，抽錄自正本）

| 項目 | 規則 |
| ---- | ---- |
| 場館範圍跟隨站台切換 | 後台各頁皆有頁面標題下方的**站台切換下拉選單**，一次僅顯示所選站台的資料——本功能各頁（機台交易紀錄、洗分出金核實、場館日結報表等）的場館範圍一律由它決定，**不另設「場館」篩選欄位** |
