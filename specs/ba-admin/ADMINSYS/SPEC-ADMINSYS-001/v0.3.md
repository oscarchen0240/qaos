## 七、後台管理員系統

### 7.1 系統使用者列表

**功能路徑：** 後台管理員系統 \> 系統使用者列表

#### 功能說明

顯示所有後台系統使用者，可依系統人員編號與角色篩選查詢，並可於列表中調整人員角色。

#### 7.1.1 角色說明

| 角色    | 權限範圍                                                                  |
| ----- | --------------------------------------------------------------------- |
| 遊客    | 無；註冊後等待配發權限                                                           |
| 客服    | 會員與代理商（不含人工出入金）、各式報表                                                  |
| 清稽核客服 | 會員與代理商（含人工出入金）、各式報表                                                   |
| 財務    | 會員與代理商（含人工出入金）、各式報表、財務管理、遊戲商管理、系統管理；可接收出金審核與 KYC 審核的提醒聲音              |
| 站長    | 會員與代理商（含人工出入金）、各式報表、財務管理、遊戲商管理、系統管理；可接收出金審核與 KYC 審核的提醒聲音；可分配站長以下的角色權限 |
<!-- INTERNAL:START -->
| 管理員   | **每個站台皆有**的最高管理者，層級高於同站台的站長：可操作自身站台及其所有子站台的全部功能，並可直接指派管理員與站長；站長唯讀的欄位（上層站台、模板）與「開通」狀態切換僅本角色可執行。可見範圍限自身站台及所有子站台——根站台 `admin` 的管理員因其子樹即全平台，故等同看到全部（見 `站台列表_spec_v07.md`「根站台」） |
| 操作員   | 場館現場人員，權限小於站長，可見範圍僅自身所屬場館；限實體機台場館使用，細部權限見 `實體機台_spec_v08.md`「角色與權限」 |

<!-- INTERNAL:START -->
> 📖 **內部補充（客戶版手冊不輸出本區塊與上表的管理員／操作員兩列）**
>
> - **「管理員」是技術端使用的角色，不對客戶揭露**——一般客戶不會知道其存在。對客戶的說明（客戶版手冊、對外文件、教育訓練）一律以**站長為後台最高權限**；「前言與通用規則」名詞對照的站長定義即依此撰寫，維持不改。同一站台內的層級為 **管理員 > 站長**。
> - **管理員不是單一的平台方帳號，而是每個站台各自都有的角色**——權限範圍跟著所屬站台走：自身站台及其所有子站台。`admin` 根站台的管理員之所以看得到全平台，是因為它的子樹就是整棵樹，不是這個角色本身有特殊的跨站權限。
> - **管理員對「自身所屬站台」本身受限**（2026-09-04 定案）：不可修改自身站台的上層站台、不可將自身站台切換為「開通」（含由「更新待審」切回）——這兩項一律由**上層站台的管理員**執行（站台一律不可刪除，2026-10-05 定案）；後端一併強制，越權一律回「無權限」；暫停／關閉與其餘欄位（名稱、網域、模板、場館設定）可自行操作。對**子站台**則有完整權限，不受此限。
> - **角色指派**：管理員可在管轄範圍內指派管理員與站長（及以下所有角色）；站長只能分配站長以下的角色權限（含操作員），**不可指派管理員、也不可指派站長**（2026-10-05 定案）。
> - **機台場館僅使用 管理員／站長／操作員 三種角色**（2026-09-04 定案）。客服、清稽核客服、財務、遊客四種角色不適用於機台場景，各機台開發包的權限表亦僅列此三種。
> - 「操作員」是**後台帳號的權限角色**；名詞對照裡的「Operator（店員）」指現場持鑰匙操作機台的人員，兩者常是同一批人但概念不同（見 `實體機台_spec_v08.md`）。
> - 各功能的細部權限矩陣分散於各功能 spec，本表僅定義角色本身：`站台列表_spec_v07.md`、`創建會員帳號_spec_v01.md`、`實體機台_spec_v08.md`（最完整）、`機台場館平台規則_spec_v01.md`、`場館日結報表_spec_v02.md`。
> - 管理員與操作員上線時，7.1.2 的「調整角色」下拉選單需一併納入這兩個角色；可選範圍依操作者而定——管理員可選到管理員，站長僅能選站長以下（不含站長）。
<!-- INTERNAL:END -->

#### 7.1.2 列表頁操作

**新增後台人員**

操作步驟： 1. 提供後台註冊連結給新人員，對方自行完成註冊 2. 取得對方的系統人員編號 3. 於列表中找到該帳號，調整角色為對應職位

新帳號預設角色為「遊客」，無法存取任何功能，須手動調整角色後方可使用對應功能。

**調整角色**

點擊列表中角色欄位，從下拉選單選擇新角色，確認後即時生效。

**篩選**

| 篩選欄位   | 說明          |
| ------ | ----------- |
| 系統人員編號 | 輸入編號關鍵字搜尋   |
| 角色     | 從下拉選單選擇角色篩選 |

填寫篩選條件後點擊「搜尋」；點擊「清除」重置篩選條件。

**列表欄位：**

| 欄位     | 說明                      |
| ------ | ----------------------- |
| 系統人員編號 | 使用者的後台帳號編號，可點擊欄位標題排序    |
| 角色     | 該使用者的角色                 |
| 建立時間   | 帳號建立時間（UTC+0），可點擊欄位標題排序 |
