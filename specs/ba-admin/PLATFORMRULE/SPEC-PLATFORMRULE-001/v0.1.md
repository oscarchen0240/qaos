## 機台場館平台規則（實體機台・開發包⑥）

> ⚠️ **開發包說明**：本檔為實體機台功能的**開發包⑥（機台場館平台規則——跨頁政策層）**，自正本 `實體機台_spec_v07.md` 抽錄而成，供負責平台層的工程師專讀；**重疊部分如有出入，一律以正本為準**，正本改版時同步修訂本檔。本包為跨頁規則彙整，**無獨立 proto**。
>
> 🎯 **核心架構要求**：排除規則必須做成**集中、可逐項解除的政策層（policy）**，後台選單顯示跟著政策層走，各功能**不得自行硬編碼帳號類型判斷**。

### 既有功能對機台帳號的排除規則

機台帳號**沿用現有的會員資料**，在會員紀錄上新增「帳號類型」欄位加以區分（線上／機台），不另外建立一套帳號系統。由於機台帳號沿用會員資料，若不特別排除，既有的會員相關功能會自動對它生效。下表逐一定義處理方式：

> ⚠️ **排除是現階段的營運決策，不代表未來不會加回來。** 實作時應做成**可逐項解除**的集中規則層（policy），不要把「機台帳號不進某模組」寫死散落在各功能內——Free Spin 已是排除規則的既有例外，未來亦可能逐項恢復適用（例如客戶提及的「開分招待」活動，見正本「機台帳號的稽核」）。某項排除解除時，後台選單的對應頁面須隨之恢復顯示（見「機台場館的後台選單」）。

| 章節 | 功能 | 機台帳號處理方式 |
| ---- | ---- | ------------- |
| 2.1 | 會員列表 | 照常顯示，不預設排除；篩選器新增「帳號類型」欄位（全部／線上／機台，預設「全部」）供區分查詢，總筆數依篩選結果計算；**提款次數／提款金額累計已核實的機台洗分與機台出金**（於「洗分出金核實」頁核實當下累計，交易完成但待核實不計、已作廢永不計；金額以站台核心貨幣原值累計、不換算 USDT，機台場館即 TWD；2026-09-04 定案；**存款次數／存款金額對稱累計機台開分與機台入金**——開分與入金不需核實，於交易完成（分數入帳）當下直接累計，金額同以核心貨幣原值。對照線上會員：系統出金於出金審核按「通過」當下累計；人工入金／人工出金一律不計入） |
| 2.1.5 | 會員詳細資料頁 | 可開啟，但 KYC、等級、優惠、邀請鏈區塊隱藏 |
| 2.2 | 加盟列表 | 機台帳號不可成為加盟商，也不計入任何加盟商的直推人數 |
| 2.4 | 推薦註冊金 | 不適用，機台帳號沒有邀請人 |
| 3.2 | 出金審核 | **不進入本流程**。機台出金為現場即時核可並印出收據，不需後台審核 |
| 3.3 | 優惠彩金審核 | 不適用 |
| 4.1 | 交易紀錄查詢 | 機台交易一併寫入，交易類型新增四項（見正本「對既有章節的影響」）；場次編號欄位線上帳號顯示「—」（2026-09-03 定案） |
| 4.2 | 注單查詢 | 機台注單照常寫入，會員編號為機台帳號；場次編號欄位線上帳號顯示「—」（2026-09-03 定案） |
| 4.3 | 返水明細 | 不適用，機台帳號不產生返水 |
| 4.4 | 稽核明細 | **照常寫入**。開分與入金比照既有的出金設定，可依幣種設定稽核倍數，**機台預設為 0 倍**（等同不設稽核門檻）；詳見下方「出金設定 TWD 頁籤」與正本「機台帳號的稽核」 |
| 4.5 / 4.6 | 加盟傭金／代理返傭 | 不適用，機台帳號的投注不計入任何上層的傭金基數 |
| 4.7 | 會員等級異動 | 不適用，機台帳號固定為最低等級且不升降 |
| 6.1 | KYC 設定 | 不適用，機台帳號五個 KYC 階段一律為「未申請」且無法申請 |
| 6.5 | 優惠活動 | 不適用，機台帳號不參與任何優惠活動與簽到 |
| 6.8 | Free Spin 管理 | **適用，同一般會員**。可將機台帳號指定加入 Free Spin 活動；免費旋轉由後台直接派發、不需玩家領取，共用帳號收得到。幣種依主站台核心貨幣（機台場館即 TWD），見正本「核心貨幣」 |

#### 為何一定要排除

機台帳號的流水是**整台機台所有玩家的總和**，量級與一位線上玩家完全不同。若沿用會員規則會出現下列問題：

| 功能 | 不排除的後果 |
| ---- | --------- |
| 返水 | 一台機台一天的有效投注是數十位玩家的加總，按會員返水率回饋，利潤會被吃掉 |
| 會員等級 | 流水累積極快，機台帳號短時間內升到最高等級，接著享有最高返水率與提領額度 |
| 加盟傭金／代理返傭 | 機台帳號若掛在某加盟商底下，整間店的流水都會算成他的業績 |
| 優惠活動 | 首儲、次儲、累儲獎勵會被反覆觸發；每日簽到變成一台機台一天領一份 |

#### 為何不以「洗分或出金時歸零」取代排除

曾評估以「每次洗分或出金時把機台帳號的累計統計歸零」取代上述排除，讓一個累計區間約略對應一位玩家的一場遊玩。**經評估不採用**：

| 規則類型 | 適用功能 | 歸零是否有效 |
| ------- | ------- | --------- |
| 按每筆注單計算 | 返水、加盟傭金、代理返傭 | **無效**。此類費用是拿結算期間每一筆注單的有效投注去乘費率，與帳號的累計欄位無關；歸零不會讓已產生的注單消失，整店流水仍會全額計入 |
| 首儲／次儲類 | 優惠活動（首儲、次儲） | **反效果**。歸零後每個區間都算「第一次儲值」，首儲獎勵可以重複領，風險比不歸零更高 |
| 累計達標類 | 累儲獎勵、累計簽到 | 歸零後永遠達不到門檻，實際效果等同排除，但規則語意不清 |
| 按累計值計算 | 會員等級 | 有效，但要額外定義歸零後的降級規則；機台等級會長期停在最低級，結果仍等同排除 |

此外，「洗分或出金 ＝ 換玩家」這個前提並不成立：玩家可能留下少額餘額直接離台由下一位接手，也可能中途出金後繼續玩。因此歸零切出的區間無法對應到單一玩家，不能拿來當風控依據。

⚠️ **場館的利潤分配一律走與場館的分潤合約，以「場館日結報表」對帳，不套用線上玩家的返水與傭金體系。** 這是上述所有排除規則的根本理由。

### 機台場館的後台選單

站台切換下拉選單選到**機台場館**時，後台選單隱藏不適用的頁面（這些頁面的功能已由排除規則排除，**現階段**留著只會是空白頁）。顯示與否**跟著站台切換走**：同一操作者切回線上站台即恢復完整選單。

| 分類 | 機台場館顯示 | 機台場館隱藏 |
| ---- | ---------- | ---------- |
| 資訊看板 | —（整個分類隱藏） | 資訊看板 |
| 會員與加盟商 | 會員列表 | 加盟列表、登入網域查詢、推薦註冊金設定、暱稱禁用詞設定 |
| 帳務管理 | 鏈上錢包管理（**僅顯示法幣 TWD 頁籤**，區塊鏈頁籤隱藏——稽核倍數設定在此）、洗分出金核實 | 出金審核、優惠彩金審核 |
| 各式報表 | 交易紀錄查詢、注單查詢、稽核明細、場館日結報表 | 返水明細、加盟傭金發放紀錄、代理返傭發放紀錄、會員等級異動紀錄 |
| 遊戲商管理 | 遊戲商管理、遊戲貢獻值設定 | — |
| 系統管理 | 公告設定、Free Spin 管理、橫幅管理、消稽核設定 | KYC 設定、會員等級設定、代理設定、加盟商設定、優惠活動管理、畫面管理 |
| 後台管理員系統 | 全部 | — |

補充說明：

  - **公告與橫幅保留**：機台場館可設定公告、上傳橫幅，於機台前台呈現
  - **遊戲貢獻值設定與消稽核設定保留**：稽核倍數大於 0 時才有實際作用（機台預設 0 倍），屬低使用但不隱藏
  - **機台場館的前台不開放自行註冊**（v07 定案維持）：註冊入口不在機台場館的前台提供，機台帳號一律由後台建立（暱稱禁用詞設定因此一併隱藏）；開放與否屬未來營運需求、時程未定。線上站台的前台註冊不受影響
  - **隱藏跟著排除規則走**：排除為現階段營運決策（見「既有功能對機台帳號的排除規則」），未來某項功能對機台帳號恢復適用時，對應頁面隨之恢復顯示——選單顯示規則應與排除規則同一來源設定，不要各自寫死

### 機台場館的遊戲更新

實體機台出廠前須送**法規審核**，審核通過後機台內的遊戲不得任意更動。因此機台場館的遊戲上架規則與線上站台不同：

| 項目 | 規則 |
| ---- | ---- |
| 預設停用 | 平台**新增**任何遊戲、或對既有遊戲發佈**更新**後，該遊戲在所有機台場館一律**預設為停用**——包含更新前原已啟用的遊戲（更新視同內容變動，須重新決定是否開放） |
| 通知義務 | 平台於新增或更新後，由**營運窗口**通知站長與場館，由他們自行決定是否開放；採人工通知，**不做系統內通知功能** |
| 開啟方式 | 由**站長**自行於 遊戲商管理 啟用該遊戲；**操作員不可操作**；平台不代為開啟 |
| 適用範圍 | 僅站台類型「機台」的場館；線上站台維持既有行為，不受本規則影響 |

### Free Spin 例外

Free Spin 是排除規則的**既有例外**，實作優惠類排除時不得將機台帳號擋在本功能外：

  - **排除規則表 6.8 列**：**適用，同一般會員**。可將機台帳號指定加入 Free Spin 活動；免費旋轉由後台直接派發、不需玩家領取，共用帳號收得到。幣種依主站台核心貨幣（機台場館即 TWD），見正本「核心貨幣」
  - **對既有章節的影響（6.8 Free Spin 管理）**：① 選擇會員時允許指定機台帳號——本項為排除規則的**例外聲明**，實作優惠類排除時不得將機台帳號擋在本功能外；② 幣種敘述由固定 USDT 改為**依主站台核心貨幣而定**（機台場館的主站台即 TWD），與前言平台幣種的修訂為同一通則

### 出金設定 TWD 頁籤

> 📖 機台的完整稽核規則（計入交易、倍數大於 0 時的核可金額扣除、稽核明細寫入、預設 0 倍的理由與「開分招待」備註）屬開發包③（`機台金流與場次_spec_v01.md`）與正本「機台帳號的稽核」小節，此處僅摘錄**設定面**。

  - **設定位置**：帳務管理 \> 出金設定，於 TWD 頁籤設定稽核倍數
  - **預設值**：**0 倍**——即開分與入金不產生稽核門檻，玩家隨時可洗分與出金
  - **對既有章節的影響（3.1 出金設定）**：現行僅依區塊鏈幣別分頁，須擴充法幣頁籤（TWD），可設定稽核倍數；機台預設 0 倍

| 項目 | 規則 |
| ---- | ---- |
| 機台場館選單顯示 | 站台切換選到機台場館時，後台選單依「機台場館的後台選單」表隱藏不適用頁面（鏈上錢包管理僅顯示法幣 TWD 頁籤）；切回線上站台恢復完整選單。隱藏**跟著排除規則走**——排除為現階段營運決策，某項排除解除時對應頁面隨之恢復顯示 |
| 遊戲更新預設停用 | 因法規（機台出廠前送審，審核通過後不得任意更動機台內遊戲），平台新增或更新遊戲後，機台場館一律預設停用（含更新前已啟用者），由營運窗口人工通知站長與場館（不做系統內通知功能），由**站長**自行於遊戲商管理啟用（操作員不可）；線上站台不受影響 |
| 前台自行註冊 | **線上站台**的前台維持開放以帳號密碼方式自行註冊，僅產生線上帳號；帳號密碼由玩家於註冊時自訂、不經系統生成，**註冊時強制綁定電子信箱**；密碼遺失走前台「忘記密碼」（不適用後台「重設密碼」）。**機台場館的前台暫不開放自行註冊**（未來營運需求、開放時程未定） |
| 時區 | 後台所有時間欄位一律顯示為 UTC+0 |
