## 前言

### 適用對象

本手冊適用於站務及相關後台操作人員，說明後台各功能的操作方式與注意事項。

### 使用說明

  - 各章節對應側邊欄的功能模組，依序排列
  - 操作步驟以流程順序呈現，請依序執行
  - 標示 ⚠️ 的說明為重要限制或不可復原的操作，請特別留意

### 名詞對照

| 名詞        | 說明                     |
| --------- | ---------------------- |
| 站長        | 擁有後台最高權限的管理者           |
| 會員        | 前台平台的使用者               |
| UTC+0     | 後台所有時間欄位統一使用的時區（協調世界時） |
| USDT      | 平台使用的幣種（USD Tether）    |
| Badge     | 畫面上用於標示狀態的色標標籤         |
| Toggle    | 開關按鈕（點擊切換開 / 關狀態）      |
| Modal     | 彈出視窗                   |
| Inline 編輯 | 直接在列表上點擊欄位進行編輯，不需另開視窗  |

### 角色與權限

後台依角色區分可看到與操作的功能範圍，不同角色登入後看到的功能模組與可執行的操作不同。如需了解各角色的權限範圍，請參閱 **7.1.1 角色說明**。

<!-- INTERNAL:START -->
> 📖 **內部補充（客戶版手冊不輸出本區塊）**
>
> 上方名詞對照的「站長＝擁有後台最高權限的管理者」是**對客戶的說法**，維持不改。同一站台內，站長之上另有 **管理員**（每個站台皆有的最高管理者，可操作自身站台及其所有子站台的全部功能、可指派管理員與站長），此角色由技術端使用、**不對客戶揭露**；另有 **操作員**（機台場館現場人員，權限小於站長）。兩者定義見 7.1.1 角色說明的內部區塊。
