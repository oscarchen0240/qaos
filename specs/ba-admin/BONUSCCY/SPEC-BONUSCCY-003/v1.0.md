# 20 紅利調整說明

> 建立日期：2026-09-08

---

## 一句話

**這次只改兩件事：存款金額在「比活動門檻」和「進玩家錢包」時分開算；
簽到活動的有效會員改讀正確的資料表。**

⚠️ **現有站台的所有數字應該完全不變。** 如果有任何數字變了（除了下面「預期會變」那一節），
就是 bug。

---

## 改了什麼

### ① 存款金額拆成兩個

以前存款金額只有一個數字，同時拿去「比活動門檻」和「進玩家錢包」。
現在拆成兩個：

|                  | 是什麼                         | 用在哪                                 |
| :--------------- | :----------------------------- | :------------------------------------- |
| **原始金額**     | 玩家實際存的錢，玩家看到的幣別 | **進錢包**、算流水倍數、算手續費       |
| **核心貨幣金額** | 換算成站台記帳幣別之後的數字   | **比活動門檻**、累積儲值統計、有效會員 |

**為什麼要拆**：玩家在 USDT 站台存 3000 TWD，活動門檻是用 USDT 訂的（例如「存 100 USD
送 30 USD」），所以要拿換算後的 100 USDT 去比；但錢包該收到的是 3000 TWD。
以前兩者共用一個數字，會出錯。

⚠️ **但現在所有存款的幣別本來就等於站台記帳幣別**（線上站台收 USDT、記帳也是 USDT），
所以**兩個數字今天是一模一樣的**，行為不會變。這次是先把結構做好。

### ② 簽到活動的「有效會員」改讀正確的表

以前**前台與後台讀的是不同的兩張表**，而且都是區塊鏈服務自己維護的明細表 ——
不但兩邊數字對不起來，那兩張表本身也不齊全（只涵蓋部分鏈／部分時期）。

|            | 以前                 | 現在                                   |
| :--------- | :------------------- | :------------------------------------- |
| 後台判定   | 區塊鏈明細表         | `deposit_log_v2`（入帳成功的都在裡面） |
| 前台進度條 | 另一張更舊的區塊鏈表 | 同上，**與後台一致**                   |

⚠️ **這是這次唯一會讓數字變的改動。**

**變化主要來自前台那條** —— 它原本讀的是更舊的一張表，落差最大；
而且它是**每次玩家打開簽到頁就重算一次、達標就直接寫入有效會員**
（後台那條要等玩家再存一筆才會重算）。

所以部署後玩家只要開一次簽到頁，就會用新口徑重算：
**進度條數字會往上跳，本來就已經達標的玩家會立刻變成有效會員。**
這是修正不是錯誤（以前是漏算），但要先讓營運知道。

## 這次能測什麼

### ✅ 可以測

|   #    | 測什麼                               | 怎麼看                                                                           |
| :----: | :----------------------------------- | :------------------------------------------------------------------------------ |
| **T1** | **前台進度條會動、且與後台一致**     | 前台簽到頁的有效會員進度條，數字應該跟後台判定的累積金額一致。以前前台永遠顯示 0 |
| **T2** | **入金金額進錢包正確**               | 存多少就進多少，幣別正確。**這是最重要的回歸點**                                 |
| **T3** | **流水倍數與手續費的基數正確**       | 存款後的「提領所需有效投注額」要以**實際存入金額**為基數算，不是別的數字         |
| **T4** | **現有 USDT 站台的紅利數字完全不變** | 首儲／次儲、累積存款活動、VIP 等級、獎勵發放金額，改前改後比對應該一模一樣       |
| **T5** | **每月重置仍正常**                   | 簽到活動若開了「有效會員每月重置」，跨月後進度應歸零重算                         |

### ❌ 這次測不了

| 測不了什麼             | 為什麼                                                                                                                                                                      |
| :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **幣別換算算得對不對** | **今天沒有任何存款會觸發換算** —— 線上站台只收 USDT，而記帳幣別也是 USDT，幣別相同就直接跳過換算。要驗證換算，得等線上站台真的開一條 TWD（或其他非 USDT）的存款通道 |

⚠️ **所以這次的測試重點是「有沒有弄壞」，不是「新功能對不對」。**
新功能（換算）要等有實際通道才驗得到。

> **機台站台目前沒有任何紅利活動，不在這次的測試範圍。** 上面所有項目都在線上站台測。

⚠️ **後台人工存款不計入紅利**（不進累積儲值、不觸發活動、不算有效會員），
所以**沒辦法用人工存款打一筆 TWD 來測換算**。
換算這條只能等線上站台實際開出 TWD 存款通道才驗得到。
