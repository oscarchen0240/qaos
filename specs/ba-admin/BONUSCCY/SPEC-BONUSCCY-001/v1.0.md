# 17 給 QA 的說明

## 一句話

**以前全系統的記帳幣別寫死是 `USDT`，這次改成「每個站台開站時自己決定」，
存在 `site_info.core_currency`，開站後不可變更。**

第一個要用 TWD 的是**機台站台**（實體機台場館）。
**現有的線上站台全部維持 USDT，不受這次改動影響。**

---

## 改之前 vs 改之後

|                      | 之前                          | 之後                                                                |
| :------------------- | :---------------------------- | :------------------------------------------------------------------ |
| 系統幣別（記帳基準） | 全域常數 `"USDT"`，全平台一種 | 每個站台一個值，查站台設定得到                                      |
| 誰決定               | 寫死在程式裡                  | 主站台開站時選定，子站台一律繼承                                    |
| 可以改嗎             | ——                            | **不行**。站台底下一出現會員就鎖死，另有 DB trigger 擋直接 `UPDATE` |
| 線上站台             | USDT                          | USDT（不變）                                                        |
| 機台站台             | 不存在                        | TWD                                                                 |

系統幣別是**平台記帳的基準** —— 報表、發紅利、算流水用哪個單位。

一個限制：**站台的系統幣別必須是啟用中的錢包幣別之一**（`wallet_currency.enabled = 1`），
否則獎勵會發到玩家看不到的錢包。注意這只保證「看得到」，**不保證「唯一」**。

---

## ⭐ 兩種站台差很多：機台只有 TWD，線上可以有多個錢包

|                        | 線上站台                                 | 機台站台                                           |
| :--------------------- | :--------------------------------------- | :------------------------------------------------- |
| **系統幣別**           | `USDT`                                   | `TWD`                                              |
| **玩家可以有幾種錢包** | **可以同時有多種**（USDT／USD／TWD⋯⋯）  | **只有 TWD 一種**                                  |
| **錢怎麼進來**         | 鏈上儲值、金流通道                       | **開分**（店員收現金加分）、**入金**（玩家投紙鈔） |
| **前台資產列表**       | 列出所有啟用中的幣別                     | **只列 TWD**（本次改的，見下表第 8 項）            |
| **後台鏈上錢包管理**   | 完整                                     | **僅顯示法幣 TWD 頁籤，區塊鏈頁籤隱藏**            |
| **前台註冊**           | 開放                                     | **暫不開放自行註冊**                               |

兩件事要分清楚：

- **機台站台只有 TWD，不是靠程式擋出來的，是它根本沒有多幣別的進錢管道** ——
  現場收現金只可能是 TWD
- **線上站台的多錢包完全保留** —— 這次沒有動存款幣別，
  線上玩家照樣可以持有非 `USDT` 的餘額

⚠️ 所以「站台的系統幣別是 X」**不等於**「玩家只能持有 X」。
線上站台的系統幣別是 USDT，玩家仍可同時持有別種幣別的餘額；
機台站台看起來「只有 TWD」是它的進錢方式決定的，不是這次加的限制。

---

## 實際被改到的地方

原本 21 處寫死 `USDT`（或寫死 `wallet_currency_id = 1`）的地方，
全部改成「去查該站台的核心貨幣」。按功能分：

| #   | 功能                   | 改了什麼                                                                                                                                                  |
| :-- | :--------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **發獎勵**             | 返水、簽到（v1／v2）、代理、推薦、推薦註冊金、累積入金、活動 —— 錢要進到「站台核心貨幣」那個錢包                                                          |
| 2   | **注單三層金額**       | `game_bet_log` → `..._wallet_reference` → `..._system_wallet_reference`，第三層的幣別與換算改依站台核心貨幣                                               |
| 3   | **後台查詢**           | 注單列表與明細、返水明細、營運日報、會員列表、Dashboard 總會員數 —— 這些的 JOIN 條件原本比對常數                                                          |
| 4   | **開站流程**           | 建站時寫入核心貨幣、新增「可選幣別清單」端點、站台查詢多回一個 `coreCurrency` 欄位                                                                        |
| 5   | **新玩家註冊**         | 初始錢包與顯示幣別改由站台核心貨幣推導（原本寫死幣別 id）                                                                                                 |
| 6   | **人工出入金**         | 四支原本沒有明確寫入幣別（靠資料表 DEFAULT 或填死 `USDT`），改成取核心貨幣                                                                                |
| 7   | **擋阻檢查**           | 搬站／改站台類型不得讓幣別與站台脫節、子站台幣別必須與主站台相同、核心貨幣必須是啟用的幣別                                                                |
| 8   | **機台站台的資產列表** | 只列核心貨幣，不再列出一排餘額 0 的其他幣別                                                                                                               |
