# SPEC-SCREENMGMT-001 畫面管理（PM 定案整理）v1.0 草稿

> 目前沒有畫面管理的正式 spec。本檔依 PM 2026-09-13 定案（CLR-SCREENMGMT-001/002）整理，供 PM 確認後匯入，作為 MAN-20260913-016 走 WF-B 的 Requirement 來源。

## 1. 範圍
後台「畫面管理」頁的區塊「前台顯示」開關對前台的效果。

## 2. 功能需求
- **R1** 區塊「前台顯示」設為 OFF 時，該區塊的內容在前台**全部隱藏**：首頁區塊卡片、底部導覽列 TAB、以及 TAB 內的遊戲列表；使用者不得經由任何入口進入該區塊的遊戲。
- **R2** R1 的效果不依賴「遊戲商管理」的個別遊戲狀態；不需要另行停用遊戲。
- **R3** 區塊「前台顯示」設為 ON 時，恢復顯示（卡片、TAB、遊戲列表）。

## 3. 不該發生什麼
- OFF 後仍可從底部 TAB 進入該區塊遊戲 → 違反 R1。

## 4. 本版不實作／作業流程
- 不支援站台核心貨幣（如機台場館 TWD）的遊戲商／遊戲：**目前由人工在 prod 先行關閉**，系統不自動過濾；未來設計另行規劃。（CLR-SCREENMGMT-001）
