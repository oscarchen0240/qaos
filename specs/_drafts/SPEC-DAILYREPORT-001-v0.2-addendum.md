## 補入 §篩選器
- 機台帳號：輸入不存在或非本場館的機台帳號時，回傳空列表（API `rows: []`），不報錯。（CLR-002）
- 結算日期：起日晚於迄日等異常組合時，回傳空列表（`rows: []`）。**待確認**：未填時是「必填阻擋」還是同樣回空列表？（CLR-003 未明說）

## 補入 §權限
- 操作員的站台切換選單不提供非自身場館（前端擋）。**待確認**：後端 API 對帶入非自身場館參數的請求如何回應（403 / 空列表）？（CLR-001 未涵蓋）

## 補入 §業務規則／日結時間
- 場館設定的「日結時間」欄位預設 00:00 UTC+0；未另設定時以此切分營業日。（CLR-004）

## 補入 §篩選器／統計週期
- 按週時，結算日期範圍內的不完整週依實際起迄日期顯示（例：09-03～09-06），合計只含範圍內營業日；完整週以週一為週起。（CLR-008）

## 補入 §列表欄位附註
- 未兌現金額：受結算日期範圍限制（結算日期仍為篩選條件），只是不受統計週期切分影響，各列皆為截至查詢當下、範圍內的累計。（CLR-009）

## 補入 §列表欄位
- 待核實洗分不為 0 的提醒標示：黃色警示標籤「⚠ 現金未確認」（與洗分出金核實／交易列表同款）。（CLR-005）
- 無資料時：列表仍列出該期間，結算期間正常顯示、各金額與筆數欄顯示 0。（CLR-006）
- **新增欄位「注單數」**：PM 提供的欄位清單含「注單數」，v0.1 列表欄位無此欄；請 Spec 作者確認定義（期間產生的注單數，同場次資訊表）並加入列表欄位。（CLR-006）
- 匯出 CSV 無資料時：推定同列表（一列 0）。**待確認**。
