# CLR-DAILYREPORT-014：REQ-DAILYREPORT-001 不符合時系統應如何反應？（Spec 未定義拒絕行為）

- 產品 / 功能：ba-admin / DAILYREPORT
- 規格：SPEC-DAILYREPORT-001 v0.2  §§功能說明/權限表（操作員越權的前後端阻擋依 CLR-DAILYREPORT-001）
- 相關需求：REQ-DAILYREPORT-001
- 提出者：agent-spec-analyst（2026-10-01）
- 狀態：OPEN

## 背景
場館日結報表依角色限制可見範圍：管理員＝管轄範圍；站長＝管轄範圍；操作員＝自身場館（v0.2 修訂：v0.1 的「Admin｜全部」改名為「管理員」，可見範圍改為「管轄範圍」）。操作員越權時前端與後端皆阻擋：站台切換選單不提供非自身場館，直接呼叫 API 帶非自身場館參數會被後端拒絕（依 CLR-DAILYREPORT-001 PM 定案，含 2026-09-14 補充；v0.2 原文未載）。
操作員越權：前端已擋（站台切換選單不提供其他場館選項）、後端也擋（直接呼叫 API 帶非自身場館參數會被拒絕），依 CLR-DAILYREPORT-001（含 2026-09-14 補充）。v0.2 新增的限制——管理員由「全部」改為「管轄範圍」——其越權（管理員或站長存取管轄範圍外場館，含直接呼叫 API）時的系統反應 v0.2 未定義，CLR-001 只涵蓋操作員，需再確認是否比照操作員（前端不提供、後端拒絕）。
