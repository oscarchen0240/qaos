# CLR-DAILYREPORT-012：場館日結報表「依場次明細」是否應列出進行中的場次（結束時間「—」、時長累計至查詢當下）？

- 產品 / 功能：ba-admin / DAILYREPORT
- 規格：SPEC-DAILYREPORT-001 v0.1
- 相關需求：REQ-DAILYREPORT-008
- 提出者：oscarchen@blockaction.tech（2026-09-22）
- 狀態：APPLIED

## 背景
Spec §背景：場次資訊表（通用，會員詳細頁機台資訊亦引用）寫「進行中的場次結束時間顯示「—」」「進行中則顯示累計至查詢當下」；§列表欄位只寫「場次編號：僅依場次明細維度顯示；另附開始／結束時間與場次時長」，未明說明細是否列出進行中場次；場次數明確為「當日結束的場次筆數」。RM 的 AC-DAILYREPORT-0083 依通用表推導「有一場次仍進行中 → 查看該列 → 結束時間「—」、時長累計至查詢當下」，TC-DAILYREPORT-027 據此設計。2026-09-22 QA 於 stage 實測並經 RD 確認：依場次明細不列進行中場次；場次時長只在結算（洗分／出金／逾時／日結）時計算一次，中途不累計。

## 可能的解讀（請勾選或補充）
- [ ] A. 明細應列出進行中場次：結束時間「—」、時長累計至查詢當下（不計入場次數）→ AC-0083 成立，現行實作須改
- [ ] B. 明細只列已結束／逾時結束／日結結算的場次 → AC-0083 作廢、TC-027 retire；另請一併決定會員詳細頁「機台資訊」的進行中場次摘要是否仍須顯示即時時長
- [ ] C. 明細列出進行中場次但時長顯示「—」（不即時累計）

## 若未回答的影響
TC-DAILYREPORT-027 無法執行；選 A 為 bug，選 B 則 AC-0083／TC-027 作廢

## PM 回覆
B：場館日結報表「依場次明細」只列已結束／逾時結束／日結結算的場次，進行中場次不列。現行實作（時長僅於結算時計算一次、明細不列進行中）符合。→ AC-DAILYREPORT-0083 作廢、TC-DAILYREPORT-027 retire；REQ-008 statement 移除「進行中場次結束時間顯示「—」、時長為累計至查詢當下」。附帶題「會員詳細頁機台資訊區塊的進行中場次摘要是否顯示即時時長」本次未決，留待 ACCOUNT／ARCADE 處理。
