# CLR-DAILYREPORT-010：「已兌現金額」以收據日還是兌現日歸屬？（同一筆出金跨日兌現時，記在出收據那天還是付現那天）

- 產品 / 功能：ba-admin / DAILYREPORT
- 規格：SPEC-DAILYREPORT-001 v0.1
- 相關需求：REQ-DAILYREPORT-011
- 提出者：oscarchen@blockaction.tech（2026-09-21）
- 狀態：ASKED

## 背景
Spec 欄位說明「已兌現金額＝當日已核實（核銷）的收據金額合計」有兩種讀法，且 spec 兩處暗示相反：AC-DAILYREPORT-0113「當日收據 200，其中 150 已核銷 → 已兌現 150」是收據日基準；現金淨收註解「代表場館端當日現金應該增減多少」是兌現日基準。例：9/10 出收據 1000、9/12 櫃檯付現核實。收據日基準 → 9/10 列 收據 1000／已兌現 1000／現金淨收 −1000（但 9/10 抽屜沒少錢）；兌現日基準 → 9/10 列 收據 1000／已兌現 0／未兌現 0（1000 對不上）、9/12 列 已兌現 1000／現金淨收 −1000（與抽屜一致）。CASHOUT spec 明說收據不設兌現時效、未兌現會長期累積，跨日是常態。此題連帶決定 REQ-DAILYREPORT-012 現金淨收是否為當日現金基礎。

## 可能的解讀（請勾選或補充）
- [ ] A. 收據日：已兌現歸在出收據那天（同 AC-0113）；單列內 收據＝已兌現＋未兌現＋已作廢 成立；現金淨收含未來才付的錢
- [ ] B. 兌現日：已兌現歸在付現那天；現金淨收＝當日實際現金增減；單列內收據與已兌現不勾稽
- [ ] C. 實務上一律當天兌現，跨日視為例外，採 A 即可
