# CLR-DAILYREPORT-013：場館日結報表對「進行中場次」的處理：CLR-DAILYREPORT-012 的定案（2026-09-22，B）與 spec 2026-09-17 修訂相反，以哪一個為準？①「依場次明細」是否列出進行中場次？②「期末餘額」是否計入進行中場次累計到查詢當下的分數？

- 規格：SPEC-DAILYREPORT-001 v0.1
- 相關需求：REQ-DAILYREPORT-008
- 提出者：oscarchen@blockaction.tech（2026-10-01）
- 狀態：APPLIED

## 背景
2026-09-17 spec 修訂（ba-spec main，場館日結報表_spec_v01.md）：「進行中場次的分數計入期末餘額…期末餘額一律取截至查詢當下的分數；『依場次明細』維度的進行中場次列改為顯示累計至查詢當下的分數（原顯示「—」，比照「場次時長」）」，場次資訊表「期末餘額」列同步修訂，並新增驗算式「期末餘額＝期初餘額＋開分金額＋進鈔金額＋損益－洗分金額－收據金額」。2026-09-22 CLR-DAILYREPORT-012 依專案收錄的 09-04 版 spec 提問（當時版本沒有 09-17 修訂），PM 回覆 B（不列進行中），AC-DAILYREPORT-0083 作廢、TC-DAILYREPORT-027 retire、TC-051～054 改到會員詳細頁「機台資訊」區塊驗證。現行實作：進行中的場次在日結報表查不到任何資料（沒有明細、沒有場次時間與期末餘額），只能從注單明細證明該場次存在。

## 可能的解讀（請勾選或補充）
- [ ] A. 以 spec 09-17 為準：依場次明細列出進行中場次（結束時間「—」、場次時長與期末餘額累計到查詢當下），期末餘額一律計入進行中場次 → CLR-012 的 B 作廢；現行實作為缺陷
- [ ] B. 以 CLR-012 與現行實作為準：依場次明細不列進行中場次，期末餘額只計已結算的場次 → spec 需撤回 09-17 的修訂

## 若未回答的影響
選 A：REQ-008、REQ-014 依 spec 09-17 修訂，恢復 AC-0083 並新增期末餘額含進行中的 AC；TC-051～054 需修訂、補新 TC；現行實作需開缺陷單。選 B：RM／TC 不變，spec 需回改

## PM 回覆
A：以 spec 2026-09-17 為準。①依場次明細列出進行中場次：結束時間「—」，場次時長與期末餘額為累計到查詢當下的值；②期末餘額一律計入進行中場次累計到查詢當下的分數（已結算的營業日仍為結算時點的值）。CLR-DAILYREPORT-012 的 B 作廢。現行實作（進行中場次在日結報表查不到任何資料）為缺陷。
