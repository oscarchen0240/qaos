# CLR-REDPACKET-056：機台扣除「未完成稽核的部分」的計算與出金後的處理：(1) 扣除的是什麼金額——剩餘未達的所需有效投注額、尚未完成稽核的紅包金額，或其他（例：30 TWD 紅包、稽核 1 倍、已打 10，扣 20 或 30）；(2) 出金依 SPEC-CASHFLOW-001@0.2 一律清空餘額，扣除後核可金額小於餘額時，被扣除的分數留在機台（不清空、不結束場次？）或作廢；洗分扣除後的餘數是否照洗分留餘數規則開新場次承接。目標與 SPEC-CASHFLOW-001@0.2、SPEC-ARCADE-001@0.8 皆未定義（原機台預設 0 倍不會觸發，紅包稽核使其可達）

## 背景
REQ-REDPACKET-030：機台場館的紅包稽核倍數預設帶 0；填大於 0 時表單顯示機台稽核警告（玩家隨時離台、稽核掛在共用帳號會卡到下一位），站長確認後可儲存。機台帳號有未完成的稽核（含紅包稽核）時，洗分與出金的核可金額須先扣除未完成稽核的部分；扣除條件為「帳號有未完成稽核」，不再以出金設定的 TWD 稽核倍數大於 0 為前提（出金設定 0 倍、紅包稽核倍數大於 0 時同樣扣除）；扣除後為 0 時視同餘額不足（SPEC-CASHFLOW-001@0.2）。扣除的計算基準與出金（一律清空餘額）在扣除後的處理見 Q03。
