# CLR-PLATFORMRULE-003：操作員角色是否可見「注單查詢」與「稽核明細」頁面？權限表未列此兩項，請補列定案

- 產品 / 功能：ba-admin / PLATFORMRULE
- 規格：SPEC-PLATFORMRULE-001 v0.1
- 相關需求：REQ-PLATFORMRULE-014
- 提出者：oscarchen@blockaction.tech（2026-09-21）
- 狀態：APPLIED

## 背景
§機台場館的後台選單（不分角色）列出各式報表分類於機台場館顯示：交易紀錄查詢、注單查詢、稽核明細、場館日結報表。§角色與權限表只有「機台交易紀錄查詢：操作員自身場館」「場館日結報表：操作員自身場館」兩列，沒有「注單查詢」「稽核明細」——spec 對操作員能否進入這兩頁是空的。REQ-PLATFORMRULE-014 依 2026-09-15 操作員登入實際選單截圖記錄：操作員選單僅含 會員列表／洗分出金核實／交易紀錄查詢／場館日結報表，即實機上看不到注單查詢與稽核明細，但此為實機行為，非 spec 明文。若依選單表主張機台場館顯示注單查詢、操作員亦屬機台場館人員，spec 無法反駁。

## 可能的解讀（請勾選或補充）
- [ ] A. 操作員不可見注單查詢與稽核明細（同現行實機）；權限表補兩列，操作員欄填「不可」
- [ ] B. 操作員可見，範圍限自身場館（比照交易紀錄查詢）；權限表補兩列，操作員欄填「自身場館」，現行實機須修
- [ ] C. 兩頁分開決定（例如注單查詢可見自身場館、稽核明細不可）

## 若未回答的影響
操作員選單完整清單無 AC 可掛；REQ-014 現有 TC 只驗「無站台列表」，注單查詢／稽核明細的可見性無法設計 TC，亦無法判定實機行為是否為 bug

## PM 回覆
新需求：操作員有權限進入「注單查詢」與「稽核明細」（可見範圍比照其他報表頁限自身場館）。→ 權限表須補兩列（操作員：自身場館）；現行實機操作員選單無此兩頁，屬未實作／須補。REQ-PLATFORMRULE-014 statement 所記「操作員選單僅含四頁」的實機描述已過時，須更新。
