## 背景
REQ-SITELIST-037：「管理員」為每個站台皆有的角色，權限範圍跟著所屬站台走（自身站台及其所有子站台），層級高於同站台的站長；管理員與站長可見範圍相同，差別在操作深度。根站台 admin 的管理員等同看到全部站台，是所屬站台的位置造成，不是角色本身有跨站權限。所有權限限制由後端每一支 API 強制，畫面上的唯讀、隱藏只是輔助；越權操作（範圍外站台、自身站台限制、越級指派角色）一律拒絕並回傳「無權限」錯誤、資料不變，不採「當作不存在／回空結果」；錯誤代碼由後端定義，尚未定案（Q03；CLR-SITELIST-015）。管理員帳號的建立方式於開發包⑧列為尚未定案（Q04）。
