# CLR-SITELIST-008：線上類型的主站台若帶有子站台，執行刪除時系統如何處理其子站台？

- 產品 / 功能：ba-admin / SITELIST
- 規格：SPEC-SITELIST-001 v0.4
- 相關需求：REQ-SITELIST-023
- 提出者：oscarchen@blockaction.tech（2026-09-13）
- 狀態：APPLIED

## 背景
CLR-SITELIST-007 已確認機台類型不提供刪除操作（只能停用），但線上類型仍照 spec 原文的一般刪除流程；線上主站台若有子站台，刪除時是阻擋、連子站台一併刪除、還是子站台改掛他處？

## 可能的解讀（請勾選或補充）
- [ ] 阻擋刪除，需先刪除或移轉所有子站台
- [ ] 連坐刪除所有子站台（含孫層）
- [ ] 子站台自動上移為根層或改掛到被刪站台的上層

## 若未回答的影響
相關 Test Case 無法設計 / 相關 Bug 無法判定是否違反規格

## PM 回覆
不論線上或機台類型，站台皆不支援刪除功能，僅能暫停或關閉（停用）。此為對 spec 原文「刪除站台」一節（點擊列表刪除、二次確認、不可復原）的重大修正——該流程實際上不存在於任何站台類型，CLR-SITELIST-007 先前確認的「機台類型不可刪除」應擴大為「所有類型皆不可刪除」。
