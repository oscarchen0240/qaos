# CLR-SITELIST-026：「上層站台的管理員」是僅指直屬上層站台的管理員，還是任一管轄範圍涵蓋該站台的祖先站台管理員（例如根站台 admin 的管理員對孫層站台）；§角色與權限寫管理員對管轄範圍內所有子站台可切任意狀態

## 背景
REQ-SITELIST-016：管理員對其管轄範圍內的子站台可切換為任意可手動選取的狀態（待開通／開通／暫停／關閉；「更新待審」僅由系統觸發、不開放手動選取）。站長不論對子站台或自身站台，僅可切換為「暫停」或「關閉」，其他狀態顯示但不可選，選取則阻擋儲存；站長以 API 送出其他狀態時後端拒絕並回傳「無權限」、資料不變（v0.7 第 59 行）。管理員對自身所屬站台僅可切「暫停」「關閉」，不可切為「開通」（見 REQ-SITELIST-035）。依 §站台狀態：「開通」由上層站台的管理員手動切換；「暫停」「關閉」可由該站台的管理員或站長切換，上層站台的管理員亦可。場館站台（含自行經營的機台主站台）不是「開通」時，該場館所有機台一律無法運作。
