# 機台開發用測試頁

arcade 沒有正式的登入與金流入口, 這兩頁是給開發測試用的。
大廳裡沒有連結, 直接打網址進入。

打開後如果是 404, 代表該環境沒有開放這兩頁, 請找前端處理。

---

## `/dev-login` — 登入

填 webOwnerId、帳號、密碼, 按登入。

畫面上會分別顯示兩個步驟的結果, **兩個都綠色才算登入成功**。
只有第一步成功的話, 後續功能仍然會失敗, 請重新登入。

## `/dev-cashflow` — 機台金流

模擬機台的入金 / 出金 / 開分 / 洗分, 會**真的動到帳號分數**。

使用前請先到 `/dev-login` 登入。

- **開分 / 洗分** — 填金額按送出, 成功就直接生效, 沒有確認這一步
- **入金 / 出金** — 兩階段, 先按 ①, 成功後再按 ② 確認, **按了 ② 才會動到分數**

頁面最上方有錢包餘額 (每次操作後自動更新), 最下方有本次操作紀錄 (重整就沒了)。

### 注意

- 顯示失敗時**不要直接重按**, 先查後台交易紀錄確認那一筆到底成立了沒有
- 洗分的核可金額會被場館門檻無條件捨去, 與你填的金額不一定相同
- 出金重按第一階會讓前一筆失效
