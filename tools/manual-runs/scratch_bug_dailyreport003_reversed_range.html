後端：query-venue-daily-report 對 settleTime.startDate > endDate 未做檢核，疑似自動對調（min/max）或忽略該條件後查詢。前端日期選擇器允許起日晚於迄日送出，依 PM 定案（不阻擋、由後端回空）可接受，非本單修正範圍。

問題詳述

場館日結報表的結算日期選 Start 2027-02-13 00:00:00、End 2026-09-01 23:59:59（起日晚於迄日）後搜尋，API 仍回傳 13 筆（結算期間 2026-09-08～09-21，1/2 頁），各金額欄與底部總計皆有值。回傳的日期全部落在 endDate 之後、startDate 之前，即後端未依指定區間篩選，而是對調或忽略了區間。

SPEC-DAILYREPORT-001 v0.1 §篩選器／結算日期
日期範圍 · 必填；不設區間上限，與手冊其他報表一致
CLR-DAILYREPORT-003 · PM 回覆（2026-09-13，已落入 REQ-DAILYREPORT-004 拒絕契約）
結算日期異常（起日晚於迄日等）：找不到資料即可，API 回 rows: []。

預期結果 / 實際結果

預期　API 回傳空列表（rows: []），列表顯示無資料、總計為 0。
實際　API 回傳 13 筆（2026-09-08～09-21），總筆數 13、開分總計 $16,922.00、現金淨收總計 $30,992.20，看起來是一份正常的報表。
  • EVD-0064選擇器 Start 2027-02-13 00:00:00 晚於 End 2026-09-01 23:59:59，統計周期按日
  • EVD-0065搜尋後列表 13 筆（09-08～09-21），底部總計有值
  • EVD-0066要求酬載 startDate=2027-02-12T16:00:00.000Z、endDate=2026-09-01T15:59:59.000Z
  • EVD-0067回應第一筆 settlePeriod 2026-09-21 完整日結資料（見下方）

複製步驟

  1. 登入 stage 後台，站台切換下拉選單切至 Arcade（機台類型站台）
  2. 進入「各式報表 › 場館日結報表」，統計周期選「按日」
  3. 結算日期選擇器 Start Time 選 2027-02-13 00:00:00、End Time 選 2026-09-01 23:59:59，確定
  4. 搜尋；於瀏覽器 Network 檢視 query-venue-daily-report 的要求酬載與回應

前置：Arcade 場館在 2026-09-08～09-21 之間已有日結資料（本例 13 個營業日）。

API URL

POST https://stage-admin-srv.alphapod.cc/api/v2/machine/query-venue-daily-report
