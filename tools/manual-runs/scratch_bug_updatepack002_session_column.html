前端：注單查詢列表元件未新增「場次編號」欄。後端：注單查詢 API 回應疑似未帶注單所屬場次 id，請 RD 確認注單資料是否已寫入場次歸屬。兩端皆須處理。

問題詳述

後台「各式報表 › 注單查詢」的查詢結果列表，欄位為：流水號、注單單號、（詳細）、會員編號、投注額、有效投注額、貢獻系數、有效流水貢獻、派彩、遊戲類型、遊戲名稱、注單狀態、派彩時間、遊戲廠商、投注時間——整個「場次編號」欄位不存在。機台帳號 ACAA00392 的注單沒有任何場次編號可見；線上帳號的注單同樣沒有欄位可顯示「—」（此句依欄位整欄不存在推論，未另行截圖）。

SPEC-UPDATEPACK-001 v0.1 §五、交易紀錄的兩項欄位規則／場次編號欄位
與線上會員共用的頁面（交易紀錄查詢、注單查詢）的「場次編號」欄位，線上帳號的資料一律顯示「—」，不留空白、不顯示 0 或 null。機台帳號顯示該筆交易所屬的場次編號。
正本 SPEC-ARCADE-001 v0.7 對既有章節的影響 › 4.2.2 列表欄位
機台帳號的注單須帶入所屬場次編號；非機台注單顯示「—」

場次編號欄為 2026-09-03 正本 v06 定案。若本 build 的交付範圍尚未包含該定案，本單應改列「未交付」而非缺陷，請 RD 確認。

預期結果 / 實際結果

預期　列表有「場次編號」欄位；機台帳號 ACAA00392 的注單列於該欄顯示該筆注單所屬的場次編號；線上帳號的注單列顯示「—」（不留空白、不顯示 0 或 null）。
實際　列表沒有「場次編號」欄位；機台注單無場次編號可見，線上注單亦無欄位可顯示「—」。
  • EVD-0062列表左半（流水號～有效流水貢獻）無場次編號欄，該列會員編號 ACAA00392
  • EVD-0063列表右半（派彩～投注時間）無場次編號欄，投注時間 2026-09-22 04:00:44、遊戲廠商 GALAXY-A

複製步驟

  1. 登入 stage 後台，站台切換下拉選單切至 arcade（機台類型站台）
  2. 進入「各式報表 › 注單查詢」，以會員編號 ACAA00392（或涵蓋 2026-09-22 的日期範圍）查詢
  3. 檢視查詢結果列表的全部欄位（左右捲動至底）
