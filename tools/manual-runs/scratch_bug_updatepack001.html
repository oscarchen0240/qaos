目前只掌握「畫面顯示錯誤」的現象，尚未取得帳戶餘額展開清單這支查詢本身的 API request/response，無法單獨鎖定是前端寫死、還是後端回傳內容本身就錯。麻煩後端先確認：查詢帳戶餘額展開清單時，回傳的幣別內容是否真的依鏈上錢包管理即時查詢產生；若後端回傳正確、前端卻顯示錯誤，才能鎖定為前端問題。

問題詳述

Arcade（機台站台）與 SpringKyle（線上站台）的帳戶餘額展開清單，皆未依鏈上錢包管理實際啟用狀態動態產生，看起來像是寫死固定顯示 TWD＋USDT 兩種幣別，違反了 spec 明訂的兩件事：幣別清單必須依鏈上錢包管理的啟用狀態產生；以及僅啟用一種幣別時不應顯示展開箭頭：

  • Arcade鏈上錢包管理只啟用 TWD，展開清單卻多出不存在的 USDT $1,000.00
  • Arcade該帳號僅 1 種啟用幣別，依規則不應顯示展開箭頭，但畫面仍可展開
  • SpringKyle鏈上錢包管理啟用 TTK、USDT，沒有 TWD 這個選項，展開清單卻多出不存在的 TWD $0.00
  • SpringKyle已啟用的 TTK 完全沒有被列出
spec 原文（多幣別錢包展開顯示／幣別清單來源）：「依「帳務管理 > 鏈上錢包管理」中狀態為啟用的幣種為準（含法幣頁籤的幣別）；狀態為關閉或禁用的幣種不列出。幣種增減隨鏈上錢包管理的啟用狀態連動，本功能不另行設定幣別清單」
spec 原文（多幣別錢包展開顯示／展開箭頭顯示條件）：「已啟用幣種超過一種時才顯示展開箭頭；僅啟用一種幣別的站台不顯示箭頭，維持單行呈現」
spec 原文（多幣別錢包展開顯示／機台場館的情形）：「機台場館的核心貨幣為 TWD，鏈上錢包管理在機台場館僅顯示法幣 TWD 一個頁籤、只啟用這一種幣別，因此機台帳號的餘額欄不顯示展開箭頭、維持單行呈現……⚠️ 實作不得把『單一幣別』寫死——幣別數量須由鏈上錢包管理的啟用狀態決定，未來場館啟用第二種幣別時展開行為要能自動適用。」這段話幾乎是針對 Arcade 這個現象的預先警告，符合「幣別清單寫死」這個最可能的根因猜測。

預期結果 / 實際結果

預期：Arcade 帳號的展開清單應只列出實際啟用的 TWD，且因僅 1 種幣別不應顯示展開箭頭、維持單行呈現；SpringKyle 帳號的展開清單應列出實際啟用的 TTK、USDT，不應出現 TWD。
實際：Arcade 帳號展開清單多出不存在的 USDT $1,000.00，且違規顯示展開箭頭；SpringKyle 帳號展開清單多出不存在的 TWD $0.00，且漏列已啟用的 TTK，只顯示 USDT $1,033.00。
