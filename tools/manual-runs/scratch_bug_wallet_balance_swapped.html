問題詳述

機台 ACAA00424 入鈔後錢包餘額為 1,100，接著在同一場次連續投注兩局、各 100，兩局都輸（前台注單紀錄損益皆為 -100，API 的 gameWin 皆為 0）。依此推算每局的投注前、後餘額，和注單 API 回傳的值比對，兩筆注單的 walletBeforeBalance 與 walletAfterBalance 都剛好對調：

注單（投注時間 UTC+0）投注前餘額（推算）投注後餘額（推算）API walletBeforeBalanceAPI walletAfterBalance
6745051（10:33:35）1,1001,0001,0001,100
6745052（10:33:56）1,0009009001,000

起始餘額 1,100 來自交易紀錄（入鈔 8798241 回傳 balance 1100，EVD-0090）。兩局皆輸，所以每局餘額只減少投注額 100。
規格說明：目前的注單規格（各式報表 4.2 注單）沒有定義這兩個欄位，本單依欄位名稱的字面意思判斷：walletBeforeBalance＝投注前餘額、walletAfterBalance＝投注後（派彩後）餘額。若這兩個欄位另有定義，請 RD 說明。

預期結果 / 實際結果

預期　6745051：walletBeforeBalance 1,100、walletAfterBalance 1,000；6745052：walletBeforeBalance 1,000、walletAfterBalance 900。
實際　6745051：walletBeforeBalance 1,000、walletAfterBalance 1,100；6745052：walletBeforeBalance 900、walletAfterBalance 1,000。兩筆的前後值對調。
  • EVD-0090交易紀錄 API：入鈔 8798241 後 balance 1100（起始餘額）
  • EVD-0091後台注單查詢：6745051、6745052，投注 100（派彩欄綠色 $100 為站台角度，代表站台贏，屬正常）
  • EVD-0093注單 API 6745051：gameWin 0、walletBeforeBalance 1000、walletAfterBalance 1100
  • EVD-0092注單 API 6745052：gameWin 0、walletBeforeBalance 900、walletAfterBalance 1000
  • EVD-0095機台前台注單紀錄：兩局損益皆為 -100 TWD（兩局皆輸）

複製步驟

  1. stage 站台 Arcade，機台 ACAA00424 開分 100、入鈔 1,000，錢包餘額 1,100
  2. 於機台前台進入 GALAXY-A 真人大廳，投注 100，該局輸；再投注 100，該局也輸
  3. 登入後台，切換至站台 Arcade，進入「各式報表 › 注單查詢」，查詢會員編號 ACAA00424
